# iOS 官方能力优先规则

适用于最新合并版的开发、源分析、迁移与验证工作，除非用户明确另定范围。

1. 涉及 iOS 语言、框架、API 或工程语义时，优先使用当前 Xcode 导出的适用 Apple 官方 skill，以及实际可连通的 Apple Xcode MCP。Xcode CLI、Swift 官方库、Apple 工具链和 Clang 的实际输出提供相应原生证据。自编代码主要承担编排、协议适配、证据核对和目标平台衔接。
2. 官方 skill 从本机 Xcode 的 xcrun agent skills export 获得，记录命令、Xcode 版本、文件摘要、选择主题和实际加载情况。未取得导出不得记 used；读取资料不等于业务结论已经复核。
3. MCP 先进行真实协议/工具发现，再按项目和只读范围调用，保存请求、原响应、错误和源码绑定。发现可用、配置存在、连接成功和实际工具调用分别记录，不互相代替。启用全局访问或改变授权范围须有用户明确授权。
4. AvdLee、Axiom、Serena、第三方 Xcode MCP 及自编分析 skill 均标记真实来源。SwiftSyntax 是 Swift 官方语法库，适配器是本工具实现；Clang 是 LLVM 工具，Apple 随 Xcode 提供的版本按工具链记录。不得统称 Apple 官方 skill。
5. 技术调用根据工程结构、语言、宿主能力、已确认构建范围、证据新鲜度、预算及既有授权自动编排。对可确定事项不要求用户选择 main/git 或手工拼命令；真实歧义列出具体缺失输入。
6. 官方能力不适用或不可用时，记录缺失能力、原始错误和选用替代的理由。允许不依赖该能力的静态分析继续；所缺编译、运行或官方审阅证据保持 unresolved/blocked，不能降低验证强度换取 PASS。
7. 每个运行收据呈现当前阶段、总步骤、完成/失败/阻塞、实际调用、选择与未选理由、输入摘要、输出证据和恢复条件。组合能力须验证下游消费，不能只测试标签或输入字段。
8. 禁止通过 CUA、Computer Use 或模拟鼠标键盘接管用户电脑桌面、操作无关应用及系统授权设置。指定测试应用/模拟器的截图、XCUIAutomation 控件查询与固定场景回放按已确认范围执行；不将“禁止桌面远控”扩大为应用 UI 测试总禁令。Preview 仅提供对应输入和配置下的组件外观证据。录屏、未指定个人真机与范围外应用没有因此获准。界面授权仍由用户手动完成，不自动打开设置或点击批准。详见 [应用 UI 验证边界](app-ui-validation-boundary.md)。
9. 通用官方技能中，桌面远控和未指定设备排除在默认调用范围之外；已授权的应用测试不等于任意设备操作授权。适用官方能力逐项说明来源、用途、应用/设备/场景绑定、读写范围、实际结果和替代路径。MCP 未启用、缺少桌面屏幕权限与某个测试后端缺失分别记录，不一概阻断其他可执行的官方 CLI 测试、静态分析或转换。
