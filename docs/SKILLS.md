- [rq-parse](../skills/rq-parse/SKILL.md)：解析用户原始需求，提取结构化信息（意图分类、领域映射、影响层次、关键实体、模糊点标记），并可选地执行竞品调研获取参考信息。当用户提出新功能需求、改进建议、bug 修复请求，或描述一个使用场景时触发。即使用户只是说"我想加个功能"、"能不能支持 XX"、"这里有个问题"，也应触发此 skill。

- [tdd-enforcer](../skills/tdd-enforcer/SKILL.md)：TDD 执行约束 skill，在 migbot-increment-applying 阶段对每个 task 强制执行 RED-GREEN-REFACTOR 循环。 覆盖：新增功能、功能变更、缺陷修复、优化或重构。 当执行代码生成任务时触发，确保先写测试、再写实现。
