图标保护仅在原pipeline调用前后作源输入核验：原audit与autofix dry-run给出原程序的潜在改写集合；非空先按源证据修复，不能使用默认倍率取尺寸；空才执行原完整结构引擎。事后目标代码变化报工具缺陷。只读guard不写目标代码/原状态账本。动态/无可测资源按原口径披露；独立原icon_fix可在核验显式source-backed计划后使用。原Image链解析对同行/同缩进有局限，保持已有正确值仅调整为后续更深缩进行可消除这类误判。
