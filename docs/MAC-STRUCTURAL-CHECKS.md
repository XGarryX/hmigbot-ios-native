# Mac 结构检查

本版保留安卓 1.5.2 的阶段、规格映射、状态格式、判定常量及 writeback 协议。slice/group 的 C2/C3 使用源码事实计算；stage 继续原路径。pipeline 真实运行原 13 检测器并归档原始测量，同时重测包内源码引用图；有可选声明时再计算完整显隐投影。最终事实按原历史与收敛规则处理，原 audit、C1/C4、finalize 和编译程序保留。

ETS 事实来自目标工程选择的官方 DevEco SDK，使用 ets-loader 自带配置。Node 优先随 DevEco 提供，也允许显式 HMIGBOT_NODE；不回退 PATH Node。SDK 选择不可用或歧义不会产生 PASS；C2/C3 保留其失败计数协议，同文件组合边测量返回输入错误 3。语法事实不等于类型编译或设备行为。

## 允许差异

- C2 按精确文件名选择，修复 APFS 把另一个小写 barrel 作为页面的错误；不按声明名全工程兜底，也不放宽同名文件原优先级。
- 原公共约定要求的 canonical Root 消费，须证明真实构造、类型与成员、消费路径、无写入/逃逸/遮蔽，不能仅凭导入放行。
- C3 排除被 SDK 证明属于另一方法的标记。体外紧邻标记只有原登记表证明本文件另一个活动未来 slot 的精确归属才可排除；自己体内（包括嵌套箭头）标记始终失败。嵌套箭头是原版也存在的漏检，原版可能 PASS。
- 合法指纹列表内混合 PID 字符串与行号整数，用稳定类型键比较；不改变历史原值、类型或重复项。损坏计数/指纹仍保留原错误行为。
- 当前 detector 失败时不采信同轮旧 PASS。旧 audit 与完整 wiring 证据按次归档，未删除；SDK facts 必须与本次 run_id 一致。
- 根目录 .hmigbot-ios/.migbot 运行目录不参与 C2 候选；结果与原版一致，采用的机制不同。原 skip_dirs 按任意层级目录名保留，合法源码 spec 目录可枚举。
- 测量途中计划/源码/登记表/handoff 变化，或适配器额外证据 IO 失败，退出 3，不读取旧 PASS、写完成或自动推进。direct CLI 也可能返回 3。这是内部输入一致性错误，不新增阶段或人审。
- 原内嵌孤儿图漏识别同文件组件组合。新鲜源码图保留原候选、VM 豁免及 WARN；官方 ETS AST 证明原非孤儿组件到同文件组件的真实调用链。死父、自递归、注释、字符串及遮蔽不构成入边。两路子进程使用相同哈希种子核对原语义，变化仅来自已证明的组合边；原始结果仍归档。

## 与原版相同的行为

真实 C1/C4/audit 失败继续阻断。清零优先于 cap，cap 优先于回归/停滞；默认 8，simple/complex 的原调用规则保留。原独立 compiled loop_runner 不表达自定义 cap，因此对应 slice/group 使用经过原入口 oracle 对照的源码收敛兼容实现，原程序未修改。

原来能容忍的历史格式继续容忍；原来拒绝的格式在测量前交回原实现，源码语法失败不会走此分流。现有 state 字典、额外键、插入次序、原始指纹及写入顺序保留。未指定上限时原版将旧 max_iter 重置为 8，此行为照旧。

CSE 明示文件可位于 C2 排除目录或项目外，只供 C3 的 SDK 事实，不混入 C2 搜索。Mac 同一物理文件的大小写、./、符号链接别名保留原语义；SDK 按设备/文件号去重，原候选名称不改。项目外 state/output 写绝对路径，与原版一致。

## 已知边界

C2 仍为原 page-wide 检查，不是控制流证明；同文件同名 handler 可能有歧义。外部文件或用户 deferred 的未来标记缺乏严格归属证明时可能保守失败，遇到后须提交真实中性证据。非法 UTF-8 可能被归为输入字节不一致（3）而非普通 detector 崩溃，仍不会通过。Mac arm64 有实际验证，未冒称 x64 或 Windows 运行验证。实际包 QA、目标编译、设备与视觉验收分别留证。

当前原始 ETS parser 对命名空间形式的自定义组件尾闭包仍可能给出诊断；工具保留该限制与诊断，不改写应用语法或将其当作已证明的绑定。
