# 转换工具发布边界

当前 `0.13.7` 发布配置为 `macos-arm64`，面向 macOS Apple Silicon。其他平台的启动器并不能替代缺失的完整辅助引擎，因此本配置不发布 Windows、Intel Mac 或 Linux 二进制。安装器在写入前检查实际宿主；卸载仍可清理此前拥有的文件。

`src/hmigbot_ios/payload_layout.py` 是打包、安装和上游来源审计共用的文件选择规则。发布保留运行入口、Python/Swift 适配代码、技能规程、目标工程模板、schema、配置模板、许可证和必要的来源清单。模板中为目标工程生成的单元测试骨架属于转换能力。工具开发者的 `tests`、`_tests`、fixtures、评估结果、现场报告、日志、缓存、归档、项目场景和其他平台资产不属于发布内容。根目录采用声明的工具目录与文件清单；新增根目录资源须先确认实际运行消费者。

两个 vendor 目录目前分别被结构检测和调度实现读取，不能按名称重复直接删除。相同摘要只证明字节重复，不证明某个路径不再被运行时使用。后续去重须先统一解析路径、保留各组件许可证与来源，再验证实际消费者。当前发布不改写闭源引擎。

来源清单保留原始完整范围，审计逐项计算本发布选择集合。应保留的文件缺失、被改写或未经核准替换仍然失败；主动排除的测试和平台资产单列，不要求安装它们。来源完整性与业务转换验收分别报告。

| 能力 | 实现和来源 | 本配置边界 |
| --- | --- | --- |
| iOS 工程与语义证据 | 按官方能力优先规则调用 Xcode 官方导出技能、只读 MCP、CLI、Swift 官方语法库与适用编译器；Python 层由本工具编排 | 发布包含调用适配器，不把静态文件读取记作成功的官方采集 |
| HarmonyOS 目标实现与编译 | 通用 ArkTS/ArkUI 模板及开发者配置的目标官方 SDK | 模板保留；真实 SDK 构建和设备结果需另行取得 |
| 调度与结构检测 | 工具自编控制层及随附的上游辅助引擎 | 仅保留当前 Mac ARM64 引擎及运行依赖，不冒充 Apple 能力 |
| iOS 专题参考 | 随附且注明真实来源的第三方参考包 | 来源和许可证保留，不标为 Apple 官方技能 |
| 应用 UI 验证 | 官方测试接口的工具适配与通用证据协议 | 只运行绑定应用/模拟器/场景；不恢复旧业务样例或桌面远控后端，许可/实现/实际执行分别报告 |
| 发布完整性 | 本工具的共享文件规则、摘要、包与安装清单校验 | 不作为应用代码转换门禁，不证明业务覆盖或设备行为 |

开发验证资料应放在外部 QA 目录。维护者可用源码中的 `scripts/release_purity.py --output <工具目录外的新报告>` 只读核对实际打包与安装集合、二进制架构及当前用户绝对路径；可通过 `--deny-pattern` 提供本次审计的私有项目词，词库不写入通用工具。实际打包后再用包清单校验，以及工具目录外的中性夹具测试已安装消费者。精简包不包含测试夹具，不能继续让发布 smoke 脚本假定包内自带 `tests/fixtures`。

此规则控制发行内容，不会自动取消 Git 跟踪，也不清洗历史提交。Git 推送范围仍需单独审阅，并遵守用户对 Git 操作的明确授权。
