# 暂不交付的可选能力

当前 `0.13.4` 的基本交付是 Mac ARM64 上的 iOS 源码分析、规格与规划、通用 ArkTS/ArkUI 转换、目标 SDK 编译和静态/路由/结构核对。

以下是上游 HMigBot 提供的高级设备或视觉执行扩展，不是 Apple 官方能力。本次发布不携带它们的公开技能、vendor 子目录、二进制或关联自动执行角色；仅保留本标记。完整原始来源清单仍保留原范围，当前来源审计会明确列出这些发布排除项。

| 可选组 | 当前状态与原因 | 再接入需要的工作 |
| --- | --- | --- |
| `arkts-scenario-runner` | deferred；设备状态准备、业务场景、界面读取和操作不属于当前基本转换范围 | 去除实际项目场景与默认业务数据，核对官方目标平台能力、开发者真实场景及明确授权，并完成独立验证 |
| `arkts-visual-verify` | deferred；高级截图/视觉执行链和较重平台运行依赖不随基本工具交付 | 明确证据来源和操作范围，验证完整依赖、超时和失败恢复，不能只恢复一个入口 |
| `arkts-ui-verifier` | deferred；界面执行与自动修复链不属于当前默认流程 | 核对可适用的官方能力、实际测试范围和授权，重新验证所有调用方 |
| `ios-screenshot-analyzer` | deferred；截图输入分析是可选资料处理，不是源代码转换的前置条件 | 审核输入来源、读取范围和独立价值，再决定是否提供可选包 |

`scenario-builder`、`visual-fixer`、`visual-fixer-reviewer` 同时暂停安装。来源规程保留在发行目录以外的维护材料中；不能把“显式选用”描述为当前安装已具备该能力。

原始 vendor 中同一截图分析扩展使用 `android-screenshot-analyzer` 名称，该来源别名一并排除，不构成另一项能力；基本 `ios-ui-analyzer` 源分析保留。

工具可接受开发者另行取得且可核验的构建、行为或视觉证据。缺少这些证据时，应写明 `not_run`、`unverified` 或 `deferred` 及恢复办法，不伪造通过，也不把可选执行链作为通用源码转换的硬门禁。此标记不授予屏幕、设备、远控或网络权限。

本次保留基本静态、资源、路由和结构引擎，以及这些当前 Mac 引擎实际需要的解释器、动态库、schema、模板、来源和许可证。闭源引擎中的文字引用不等于已证明的运行依赖；当前结构流水线的真实调用与文件边界核验分别记录。
