# 旧可选后端的延期与官方应用测试边界

当前 `0.13.7` 的基本交付是 Mac ARM64 上的 iOS 源码分析、规格与规划、通用 ArkTS/ArkUI 转换、目标 SDK 编译和静态/路由/结构核对。

以下是上游 HMigBot 提供的旧设备或视觉执行扩展，不是 Apple 官方能力。当前发行仍不携带这些旧公开技能、vendor 子目录、二进制或关联自动执行角色；完整原始来源清单保留原范围，来源审计明确列出排除项。该决定不能被解释为禁止所有应用截图或官方 UI 测试；指定应用的官方适配按 [应用 UI 验证边界](../rules/app-ui-validation-boundary.md) 独立实现与取证。

新适配入口、配对与复查的使用边界见 [应用 UI 测试规程](APP-UI-VALIDATION.md)。入口存在、准备产物、实际设备调用与验收通过分别记录，本文不把实现中的入口或清单条目当作已完成实测。

| 可选组 | 当前状态与原因 | 再接入需要的工作 |
| --- | --- | --- |
| `arkts-scenario-runner` | deferred；旧平台执行链、实际项目场景及默认业务数据不恢复到基本发行 | 去除项目数据，按官方平台能力和明确应用/设备/场景重新适配与验证，不能把 Android 脚本当作 iOS 实现 |
| `arkts-visual-verify` | deferred；高级截图/视觉执行链和较重平台运行依赖不随基本工具交付 | 明确证据来源和操作范围，验证完整依赖、超时和失败恢复，不能只恢复一个入口 |
| `arkts-ui-verifier` | deferred；旧自动修复链及其平台运行依赖尚未恢复 | 核对官方能力、实际测试范围和授权，重新验证所有调用方；不代替新的应用测试适配器 |
| `ios-screenshot-analyzer` | deferred；此旧扩展未交付，不代表禁止采集或分析指定应用截图 | 新的官方截图和通用证据分析按真实入口/输出单独说明；不能只改标签声称旧后端可用 |

`scenario-builder`、`visual-fixer`、`visual-fixer-reviewer` 同时暂停安装。来源规程保留在发行目录以外的维护材料中；不能把“显式选用”描述为当前安装已具备该能力。

原始 vendor 中同一截图分析扩展使用 `android-screenshot-analyzer` 名称，该来源别名一并排除，不构成另一项能力；基本 `ios-ui-analyzer` 源分析保留。

工具可接受开发者另行取得且可核验的构建、行为或视觉证据；已接通的官方适配器也可在确认范围内生产证据。每项分别记录许可、宿主可用、实现入口、实际执行和验收结果。缺少证据时写明具体 `not_run`、`unverified` 或 `deferred` 与恢复办法，不伪造通过，也不把可选执行链作为通用源码转换硬门。此标记不授予桌面远控、录屏、未指定设备或网络权限。

本次保留基本静态、资源、路由和结构引擎，以及这些当前 Mac 引擎实际需要的解释器、动态库、schema、模板、来源和许可证。闭源引擎中的文字引用不等于已证明的运行依赖；当前结构流水线的真实调用与文件边界核验分别记录。
