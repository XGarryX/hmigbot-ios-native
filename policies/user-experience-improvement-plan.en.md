# HMigBot-iOS local data behavior / 本地数据说明

Version: 0.5.0

This distribution installs no upload hooks and requires no telemetry enrolment for local migration.
Source files, specifications, build logs and test evidence remain in their chosen local locations.
Explicit cloud builds or third-party tools use their separately configured services and authorization.
The original publisher's unmodified policy is archived under vendor/hmigbot/policies for provenance;
it is not a claim that this distribution has enrolled the user or uploaded any data.

本包不安装上传 hooks，不以同意上传作为迁移前提。源码、规格和本地验证材料保留在指定目录。
显式云构建或外部工具按其实际配置及授权执行；不能把本地 consent 字段当作已上传的证明。
原发布者政策完整保留在 vendor/hmigbot/policies，仅用于来源追溯。
