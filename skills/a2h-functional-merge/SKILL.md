# iOS 功能事实合并

输入各 target/module 的事实、功能登记、已有 feature-index 和决策。
只合并本次授权范围；源版本不一致的分片先标过期，不以较新时间戳自动覆盖。

1. 对齐入口、业务目标、状态和副作用，按行为判断相同功能，不按类名或文件名。
2. 共享服务不自动把多个不同用户功能合成一项；相同功能多入口保留不同前置态。
3. 保留 Swift/Objective-C 语言语义、SwiftUI/UIKit UI 关联和所有源证据。
4. 冲突逐条标事实矛盾/配置差异/产品决策，回原作者或读取源码消歧。
5. 稳定 ID 不重排、不复用；AC 真值来自源或批准决策，不能采用目标实现作为裁决。
6. 合并后核对丢失/重复、源码归属、decision/supersedes/addendum 关联与范围。

输出更新后的登记和具体合并说明，交 a2h-spec 的原 baseline；不创建独立状态机引擎。
