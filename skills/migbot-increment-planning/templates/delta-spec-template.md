## 6. 分级规格

> 说明：对于有级别区分的需求（如高负载检测、性能分级等），定义各级别的阈值和采集策略。

### 6.1 主要资源分级

| 级别 | 阈值条件 | 摘要日志 | 详细日志 | 上层维测采集 |
|------|---------|---------|---------|-------------|
| L0   | [区间下限, 区间上限] | 整机负载+Top3 | 无 | 无 |
| L1   | (区间下限, 区间上限] | 整机负载+Top3 | 无 | 按需 |
| L2   | (区间下限, 区间上限] | 整机负载+Top3 | 全量数据 | kmsg+trace+perf |
| L3   | (区间下限, 100%] | 整机负载+Top3 | 全量数据 | **不采集** |

### 6.2 状态机规则

- **进入更坏级别**：度量越过准确阈值即判，无迟滞
- **回弹更好级别（迟滞）**：恢复方向施加迟滞系数——CPU ×0.8，内存 ÷0.8
- **最小驻留**：无论升/降，连续 N 次检测判定为同一级别后才切换
- **限频**：取证最小间隔 N 分钟；上报最小间隔 N 分钟
