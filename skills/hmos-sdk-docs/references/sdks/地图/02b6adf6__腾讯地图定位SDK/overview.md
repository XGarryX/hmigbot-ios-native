### SDK介绍

腾讯定位 SDK 是一套基于 HarmonyOS NEXT (API 12) 及以上版本设备的应用程序接口。通过统一便捷的接口,您可以轻松使用腾讯定位服务,构建 LBS 应用程序。

腾讯定位 SDK 包括 GPS 定位与网络定位,实现了经纬度坐标偏转与当前位置的 POI 名称、地址或者行政区划的查询。
