# Tencent Location SDK

## 0x01 简介

腾讯定位 SDK 提供便捷统一的定位接口,让开发者可以快速接入并构建自己基于位置的应用。SDK 支持 HarmonyOS NEXT 以及以上的系统。

提供的主要功能有:
* 连续定位
* 单次定位
* 最后位置
* 获取逆地址信息和 POI 信息
* 后台定位
* 地理围栏

## 0x02 安装

```
ohpm install @tencentmap/location_sdk
```
