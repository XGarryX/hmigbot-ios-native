### SDK介绍

协同签名移动端SDK ,是一个为移动端应用提供一站式电子签名与数字证书服务的产品。其核心功能模块如下:

1、证书管理:支持激活码、扫码下载证书等多种方式,满足不同场景下的证书获取需求。

2、签署能力:提供批量签名、扫码签名等多种签署模式,适配复杂业务流程。

3、工具与配置:支持设置个人印章图片、证书解析等辅助功能。

### 核心优势

1、支持主流移动智能设备,无需额外的硬件投入,节约建设、运维和管理成本;

2、支持企业微信等 APP 调用,支持微信、钉钉等 小程序调用;

3、提供数字证书、身份核验 CTID、短信、生物 识别等多种认证源;

4、协同签名系统采用密钥分割技术和协同签名技 术,实现密钥分量在移动端和服务端独立生成和 存储。签名过程中,移动端和服务端协作,共同完成完整签名;
