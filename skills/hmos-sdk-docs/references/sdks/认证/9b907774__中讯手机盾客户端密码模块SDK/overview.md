### 中讯手机盾客户端密码模块SDK

中讯手机盾客户端密码模块SDK 是面向移动互联网安全的软件密码模块,提供给需要密码安全功能的应用程序调用,为移动互联网应用开发提供基于国产密码算法的安全服务功能。为保证移动终端私钥的安全性,手机盾采用私钥分量与协同运算的方式,与服务端密码模块协同工作,为移动智能设备提供密码服务。

### 东方中讯数字证书认证有限公司

         东方中讯数字证书认证有限公司成立于2001年,注册资本3000万元,主要从事电子认证服务、信息安全产品研发与服务、信息安全服务、增值电信业务等业务,是国家密码管理局、工信部许可的全国性合法从事电子认证服务的第三方权威机构,是可以信赖的、专业的信息安全服务机构。

### 核心优势

  * 手机盾客户端密码模块的产品形态为客户端APP,提供SM2协同密钥生成与存储、会话密钥生成、证书申请与证书存储、协同签名/验签、加密/协同解密、身份鉴别等功能,支持国密SM2、SM3、SM4密码算法。手机盾客户端密码模块可广泛应用于电子政务、电子商务、医疗能源、企业、教育等行业的移动安全应用场景中,在移动智能终端中无需使用硬件密码模块,通过移动端密码模块与服务器端手机盾协同签名(密码模块)配合,即可实现在移动智能终端下的签名验签、身份鉴别、数据加解密等服务,确保关键数据在交易过程中的完整性、机密性和不可抵赖性。
