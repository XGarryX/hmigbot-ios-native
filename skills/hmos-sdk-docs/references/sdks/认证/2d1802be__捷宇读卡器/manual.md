# 捷宇读卡器 

设备支持社保卡、二维码、身份证、IC卡识别,支持定制,配置以订单为准 

## 一 、配件清单 

智能交互终端 

- 5V/2A电源适配器 

- 数据线 

- 安装说明书 

## 二、接口与机身分区 

### 外接接口 

PSAM、RJ11、USB Device、电源接口 

### 机身功能区 

磁卡刷卡槽、指示灯、二维码扫码区、IC卡插卡口、身份证读卡区 

## 三、使用操作 

1. 开机:接上电源适配器,设备自动开机 

2. 二维码:条码对准扫码区扫码识别 

3. **IC** 卡:按标识方向插入IC卡槽读写 

4. 身份证:证件平放读卡区读取 

## 四、注意事项 

1. 电源适配器AC220V输入、DC5V输出,匹配市电电压 

2. 禁止淋水,进水立即断电;非专业人员禁止拆机,私自拆机影响保修 

3. 电源线不可重压、过度弯折,防止漏电起火 

4. 设备工作温度:-5°C~+45°C 

## 五、常见故障排查 

1. 设备不开机:检查适配器通电、电源线插接牢固,更换插座重试。 

2. 扫码无反应:条码摆正紧贴扫码窗口,避免强光直射镜头。 

3. **IC** 卡读取失败:卡片芯片洁净,沿正确方向插卡。 

4. 身份证读不出:身份证放平紧贴读卡区,该功能如为选配需确认硬件标配。 

5. 通讯连接失败:重新插拔USB线,更换设备接口。
