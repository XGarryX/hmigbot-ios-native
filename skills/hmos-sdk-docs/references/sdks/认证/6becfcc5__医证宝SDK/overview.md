### SDK介绍

医证宝SDK,是一个提供数字证书全生命周期管理的客户端集成工具。本SDK封装了证书申请、安全存储、授权登录以及P1/P7数字签名等功能,并内置可定制UI页面,帮助应用快速实现基于数字证书的身份认证与电子签署。

数字证书申请:生成SM2/RSA密钥对,完成CSR提交与证书自动存储

授权登录:基于证书签名验签换取授权码,实现免密身份认证

数字签名:支持P1/P7格式对原文进行签名并返回签名值

UI组件:提供证书申请、授权登录等可定制界面,降低开发成本

### 提供商介绍

四川省数字证书认证管理中心有限公司(四川CA)成立于2007年,是经工信部、国家密码管理局许可的第三方电子认证服务机构及国有网络安全企业,作为全省统一数字认证体系承建者,以商用密码技术为核心,面向政府、企业及个人提供数字证书、电子签名、电子签章等产品与服务,解决数字化业务中的身份可信、数据安全及电子文件合规问题,业务覆盖电子政务、医疗、金融、交通等领域,有力支撑“智改数转”与数字生态安全建设。

### 核心优势

1、国密合规,安全增强:内置SM2/RSA双算法支持,结合手机盾与人脸识别技术,实现数字证书全生命周期管理(申请、存储、签署),满足国密改造要求。

2、开箱即用的UI组件:封装完整的证书申请、授权登录、签名页面,支持主题定制,无需额外开发界面,大幅缩短接入周期。

3、高兼容性与异步回调:底层适配主流系统版本,所有操作均提供异步回调与详细状态码,保证高并发场景下的稳定与流畅。
