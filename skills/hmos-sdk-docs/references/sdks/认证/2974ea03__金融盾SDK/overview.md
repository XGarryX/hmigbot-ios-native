### SDK介绍

是一款面向移动设备实现便捷认证、安全交易保护的创新产品,该产品通过手机设备的TEE/SE硬件安全环境存储客户的数字证书、密钥等敏感信息,从而实现与二代实体UKEY - “所见即所签”相同的功能,用于替代实体UKEY、软证书、远程人脸、短信等认证工具,建立了便捷、安全的服务模式。

  * ### 提供商介绍

国民认证科技(重庆)有限公司成立于2015年,国民认证的目标是提供创新的端到端的身份认证技术和方案,构建和确保真实的人与虚拟世界的可信连接,为用户打造安全便捷的网络服务基础。FIDO被誉为当前身份认证业界的最佳实践,代表了现代身份认证的发展趋势,公司向主流互联网服务商、政府、企业、金融机构、硬件制造商、生物认证技术商提供完整的身份认证解决方案。
