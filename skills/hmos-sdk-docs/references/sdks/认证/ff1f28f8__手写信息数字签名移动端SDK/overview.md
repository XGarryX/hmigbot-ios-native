公司以密码技术为核心,拥有数字证书认证、电子签名等产品线,覆盖政务、医疗、金融、教育等数十个行业,服务超过30家国家部委及3000家大型企业。自主研发支持国密算法的CA认证系统,承担国家十三五重点研发计划等60余项课题,牵头和参与制定170余项行业标准,参与北京奥运会、国庆70周年、APEC峰会、一带一路高峰论坛等国家重大活动信息安全保障。2023年加入云南商用密码产业链技术创新战略联盟,2025年9月控股股东变更为北京数据集团,实际控制人保持为北京国资公司。

### 核心优势

1、部署灵活:产品支持多种应用终端,可扩展多种规格型号的 前端输入设备和身份识别设备。提供丰富的二次开发接口,客户可根据自身业务流程进行灵活集成。提供本地部署和云服务调用;

2、最小化改造:产品不对原有业务流程进行重大调整,无需对原有单证系统进行复杂改造,让项目成本最小化;

3、高性价比:优化业务流程,提高业务办理效率,节省纸张、打印耗材、单据管理、存储等成本;

4、成熟可靠:历经近 300 个项目锤炼,产品成熟稳定,每年提供上亿次的手写数字签名服务,品质可靠;

5、高安全性:为签名人颁发的数字证书中扩展签名人手写签 名图像和其他身份特征信息,同时在签名时加盖时间戳,实现该数字证书与无纸化单证的唯一对应关系,杜绝此证书被应用到其它场景;

6、可信合法:产品应用数字签名技术,对电子单证进行认证,保证其符合《电子签名法》;
