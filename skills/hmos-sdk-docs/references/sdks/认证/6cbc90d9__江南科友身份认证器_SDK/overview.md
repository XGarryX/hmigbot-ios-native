### SDK介绍

江南科友身份认证器 SDK ,是基于动态口令实现的身份认证工具,包括以下 API 功能。

  * 注册动态令牌:使用序列号和激活码、加密的种子密钥和账号信息以及令牌URL注册动态令牌

  * 生成动态口令:使用指定的令牌生成当前时间周期内的口令

  * 动态令牌管理:包括创建动态令牌、注销动态令牌、获取动态令牌
