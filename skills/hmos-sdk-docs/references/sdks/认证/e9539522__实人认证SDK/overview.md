### SDK介绍

实人认证SDK,提供活体检测、身份证OCR、身份证二要素、人像比对等自然人身份核验服务,用于确认当前业务操作是认证用户本人完成的。

  * 活体检测: 通过SDK刷脸界面,完成指定动作(张嘴、摇头等),判断是否为真实自然人,并返回一张提取的人脸图片用于下一步对比验证。
  * 身份证OCR: 通过扫描采集身份证照片中的有效信息,识别并返回二代居民身份证正反面的关键信息。
  * 人像比对: 在核验用户身份信息的同时、判断图片人像和身份证信息是否为同一人,确保当前操作人为本人。可应用于远程开户、在线教育、刷脸支付等场景。
  * 身份证二要素: 输入姓名和身份证号,通过官方权威核查,实时校验此二要素是否一致。适用于所有需要实名认证的场景,帮助企业完成实名认证流程。
