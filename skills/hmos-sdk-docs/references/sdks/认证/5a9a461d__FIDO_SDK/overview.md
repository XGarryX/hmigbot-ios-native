### SDK介绍

国民认证基于TEE FIDO可信认证SDK,以先进的FIDO身份认证协议为基础,充分利用终端的安全能力,采用可信执行环境(TEE)和安全器件(SE)来保护身份验证的关键模块,结合密码技术,通过指纹、人脸、虹膜等生物特征识别方式进行快速认证,兼容PIN码、手势、数字证书(金融盾)等认证方式,通过统一用户身份管理、规范化认证服务接口、快捷接入各类认证技术等全面的标准化架构能力,支持多渠道应用的快速接入,构建数字化进程中的身份认证产业生态。

### 核心优势

**安全性**

硬件级安全保障。采用可信执行环境(TEE)或安全芯片执行关键操作及安全存储密钥,保证安全隔离;终端设备验证。设备认证器预置验证私钥,可由服务端进行验签,确保设备本身的合法性。

**扩展性**

通过FIDO协议将设备层和服务层的接口进行标准化,支持多种认证手段采取统一的认证协议,共用同一个身份认证后端服务,系统建设维护成本低。

**可用性**

用户体验好。用户仅需刷指纹,无需记忆密码,无需携带辅助设备,拥有更快捷、更安全、更自然的体验

**隐私性**

保护用户隐私,使得用户信息不被泄露且无法被非法追踪。由于FIDO创新架构采用本地生物特征识别方案,生物特征不离开本地设备的安全环境,用户隐私得到保护。

**合规性**

遵照国际国内相关行业标准,提供数字身份认证管理产品与服务,合法合规,安全可靠。
