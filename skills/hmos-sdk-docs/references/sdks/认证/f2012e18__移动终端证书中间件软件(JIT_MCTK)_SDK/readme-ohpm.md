# 接口说明

注意事项:

1:所有接口中的pin 参数,长度为 6- 16 字节

2:所有涉及到证书主题的参数,请按照格式/C=CN/CN=\*\*\*进行填写,其中\*\*\*内容长度不能超过45字节

3:协同密码模块不支持密钥长度 :4096

# 使用

通用流程:

1:使用获取设备ID接口或是使用业务方自己定义的ID内容

2:确定要存储证书秘钥对的路径,设置对应的日志的接口(非必选)

3:进行初始化操作(确定好自己的业务方式,是软证模式还是密码模块模式)

4:初始化方法如下代码,由于密码操作耗时时间不确定,会随着CPU的性能发生变化,推荐初始化之后操作的业务代码都在子线程中执行(

推荐使用worker),

    public iniCoMctk(certPath: string, deviceID: string) {

        console.log(TAG + "iniCoMctk()方法开始")

        //0:软存储 1:协同密码模块 2:非协同协同密码

        const mode = 1

        this.mctk?.init(mode, certPath as string, this.uniqueID, this.coIp, parseInt(this.coPort), deviceID, this.coEmail,

        () => {

        console.log(TAG + "sdk iniCoMctk 协同 初始化成功")

        }, (Error) => {

        const message = 'sdk 初始化失败 code码为' + Error.code + '错误信息为' + Error.msg

        console.log(TAG + message);

      });

    }

5:执行后续业务操作接口(参考下面接口方法)
