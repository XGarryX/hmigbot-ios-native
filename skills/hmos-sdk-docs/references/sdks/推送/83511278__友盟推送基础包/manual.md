# 集成文档 

- 1、 获取SDK 

   - 安装SDK 在DevEco Studio 5.x 版本的IDE 中,从顶部菜单Tools->Partner SDK 的 Analysis 分类中找到 【友盟common SDK】 点击install、 【友盟统计分析(U-APP)】 的 包,点击install 按钮、从顶部菜单Tools->Partner SDK 的push 分类 【 **友盟消息推** 

   - **送(U-Push)】** 点击install 按钮、 和 **【友盟推送基础包】** 点击install 按钮。 

   - 注意:消息推送的SDK 接入需要将上述4 个SDK 均引入后才可使用 

- 2、 快速开始,可完成基础的SDK 集成,详见 

   - https://developer.umeng.com/docs/67966/detail/2808154; (其中由于已使用 install 安装,则忽略第一步的SDK 安装,可从第二步集成SDK 开始)接入完成后即可 发送消息。 

- 3、 高级功能:如需要 修改「通知大图标、通知权限、角标、获取厂商Token、标签与别 名、推送功能开启与关闭、自定义信息」 等功能接入可详见: 

https://developer.umeng.com/docs/67966/detail/2807898 

- 4、 如需要使用华为厂商通道可详见: 

https://developer.umeng.com/docs/67966/detail/2808221
