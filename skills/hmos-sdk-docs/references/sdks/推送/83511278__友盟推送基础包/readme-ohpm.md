# 友盟sdk utunnel包

## 系统API要求
  鸿蒙NEXT API12 以上

## 快速开始
- 安装sdk
在项目根目录执行如下命令,安装友盟sdk的通道包,不能单独使用,需要配合  @umeng/push 一起使用

```shell
ohpm install @umeng/utunnel --registry=https://ohpm.openharmony.cn/ohpm
```
