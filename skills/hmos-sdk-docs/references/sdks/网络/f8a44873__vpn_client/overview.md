### 核心优势

1.国密合规与安全:客户端侧全链路防护(适配服务端合规)

客户端 - 服务端协同合规:全面覆盖 SM2-SM4 国密算法,客户端可与渔翁信息后端国密 VPN 服务端实现算法、协议全兼容,满足政务、金融 “等保 2.0 三级及以上” 对端到端加密的要求;

2\. 开发集成体验:低门槛实现客户端 - 服务端隧道对接

轻量化快速集成:提供客户端核心 API(含证书导入 / 更新、隧道建立 / 断开 / 重连、隧道状态监听等)、完整客户端 Demo 工程(ArkTS语言示例)及详细开发文档,开发者无需掌握国密算法底层逻辑,短期内即可完成客户端与后端 VPN 服务端的基础隧道对接;
