### SDK介绍

奥联商用密码中间件软件密码模块,支持多种国密、国际算法,包括 SM2、SM3、SM4、SM9、ECS 等商用密码算法,支持 3DES、AES、 RSA、ECC、SHA 系列等国际密码算法,以及高级算法如 FPE、DAE 等。

主要功能如下:

  * 数据加解密

提供SM2、SM3、SM4、SM9国密算法及主流国际算法的加解密运算,支持对数据、文件、邮件等加密保护,有效防止数据被破解风险,满足应用高安全场景。

  * 签名验签

提供SM2、SM9算法及CA证书体系的协同签名,有效防止数据被篡改风险和身份伪造,满足密评密改需求场景。

  * 身份认证

提供多因子认证、扫码认证及生物识别认证,为传统认证方式增加安全能力,满足密评密改需求场景。

  * 通道加密

提供国密SSL、TLS、SRP5、SOCKS代理等多种通道传输加密方式,打通内网通道并提升资源访问安全,满足密评密改需求场景。
