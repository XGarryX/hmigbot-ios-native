### 第一章 前言 

#### 1.1 概述 

本文档为TunnelAPI 接口ArkTS 语言手册,对接口中定义的数据结构、接口函数进行详 细说明。用于指导用户在TunnelAPI 接口开发包的基础上进行二次集成开发;以及如何正确 的安装、部署、配置TunnelAPI 接口开发包。以达到正确访问三未信安SSL VPN 网关提供的 国密服务的目的。 

#### 1.2 适用对象 

本文档主要适用于以下读者对象: 

- ⚫ 密码设备售后工程师 

- ⚫ 密码设备售前工程师 

- ⚫ 应用系统开发工程师

### 第二章 开发包简介 

TunnelAPI 开发包以 HAR 库的方式提供给应用系统进行集成。开发包内容 包括各系统下的库文件、调用 demo 工程、接口开发手册文档等。TunnelAPI 使 用 HarmonyOS 的 vpnExtension 扩展,需要使用真机调试。 

#### 2.1 支持操作系统 

##### TunnelAPI 支持如下操作系统: 

⚫ HarmonyOS 5.0.0 

#### 2.2 接口库集成 

一、引入 TunnelAPI 接口库 

将 libtunnelapi.har 包文件放入项目适当的文件夹中,如 libs 或 assets 目录, 并把该 har 包文件加载到项目中。路径确定以后在开发工具的终端中执行 ohpm install ,执行成功,在目录中出现 oh_modules 文件夹。 

TunnelAPI 接口使用手册 V1.0 

##### 二、权限设置 

集成该 har 包需要 app 具有网络权限,在 entry 的 module.json5 文件中添加 ohos.permission.INTERNET 权限 

##### 三、添加 VpnExtAbility 

复制 demo 中的 MyVpnExtAbility.ets 文件到合适目录下。并在 module.json5 文件中添加配置。 

TunnelAPI 接口使用手册 V1.0 

注意: 

1. module.json5 中添加的 type 类型需要写 vpn,如果编译报错提示没有 vpn 类型,就在报错提示的 enum 中手动添加上 vpn。 

2. MyVpnExtAbility.ets 文件中的 blockedAppName 要改成项目实际的包名

四、启动和停止 VpnExtAbility 

引入 vpnExtension, 通过 vpnExtension.startVpnExtensionAbility 和 

vpnExtension.stopVpnExtensionAbility 启动和停止 VPN。Want 对象如下图所示, 注意 bundleName 和 abilityName 按照实际情况填写。

##### 五、接口调用 

接口调用都在 MyVpnExtAbility.ets 文件中,只需要修改个别参数即可,具体 流程请参考 demo 。
