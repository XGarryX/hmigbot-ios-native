### **2.3** 、注意事项 

#### 2.3.1、应用签名打包 

集成完 SDK,需要打包 app 或 hap 交付联软实施相关人员进行发布,在联软管理平台进行发 布后,接口方可正常返回。 

手机安装调试的 app 应用签名必须和 EMM 管理平台中上传 app 文件使用同一应用的 Profile 文件签名的安装包。(正式、测试签名文件都可以,但不能是随机签名文件) 

#### 2.3.2、SDK日志 

如果集成 SDK 中遇到问题,可以提供 EMM SDK 日志反馈现场同事,SDK 日志路径: /data/app/el2/100/{集成应用的包名}/files/emm/EMMLog 将该目录下的文件压缩反馈出来,如 果该文件夹未生成日志文件,请确保 SDK 是否初始化成功。 

#### 2.3.3、SDK版本更新 

只需要更新替换一个 har 文件:EMMOpenSDK.har。

#### 2.3.4、网络框架支持 

目前鸿蒙网关隧道支持代理转发基于 **RCP** 网络框架(鸿蒙推荐方式)的内网域名和内网 **IP** 地址 ,支持代理转发基于鸿蒙 web 容器(webview)加载的内网域名和内网 IP 地址,支持代理 转发基于 http 网络框架的内网域名(支持一对一映射解析)和内网 IP 地址。 

基于 RCP 网络框架需通过 SDK 接口配置域名拦截器(接口 3.3),基于 http 网络框架和 web 容器访问不需要额外 SDK 配置。 

基于 AVPlayer,Video 系统组件访问在线音视频需将媒体资源通过 RCP 网络框架下载到本地 后再进行播放预览。 

- 基于 Request 系统接口进行上传或下载文件的功能需要换成 RCP 方式进行访问。 

RCP 网络框架介绍: https://developer.huawei.com/consumer/cn/doc/harmonyos-references-V13/remote-comm

### **4.1** 、调用 **SDK** 接口报连接服务器异常 

#### 信息描述 

W [RcpHttpImpl] https://www.xx.com:xxxx/emm-api/authorization/loginV1.json _doRequest error: {"code":1007900007,"data":"Couldn't connect to server"...} 

- W [EMMToolsImpl] emmauth authUserName onFail. auth END.. error, errCode:4109, message:连接服务器异常,请检查网络再重试 

#### 排查手段 

- 1、请确认初始化配置地址和端口是否正确(联系 EMM 管理员进行确认) 

深圳市联软科技股份有限公司Leagsoft Technologies Inc. http://www.leagsoft.com 

公司机密 

- 2、请确认设备当前的网络是否正常,通过手机直接 ping 服务器地址或通过浏览器直接访问: - 

- https://#serverhost#:#apiport#/emm api/ 

### **4.2** 、集成 **SDK** 后 **APP** 网络请求无法通过安全隧道正常访问 

#### 信息描述 

集成 SDK 的 APP 请求内网接口报“连接超时”、“无法连接服务器”。 注意:以上报错信息只有集成通过 **EMM** 安全隧道转发网络的情况才适用 

#### 排查手段 

- 1、请确认是否正常调用用户认证接口并再认证成功后才能正常发起网络请求。 

深圳市联软科技股份有限公司Leagsoft Technologies Inc. http://www.leagsoft.com 

公司机密 

- 2、请确认请求内网的 IP 和端口地址是否已经进行访问控制列表配置(联系 EMM 管理员确认) 

### **4.3** 、关闭离线默认水印 

#### 信息描述 

集成 SDK 后会默认带上 EMM 离线水印,可以通过接口进行关闭 

#### 排查手段 

- 在 SDK 初始化方法后面调用关闭离线水印的 SDK 方法。 

EMMToolsUtil.setOpenOfflineWatermark(false);//关闭离线默认水印
