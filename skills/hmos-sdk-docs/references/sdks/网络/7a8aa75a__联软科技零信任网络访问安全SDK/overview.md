### 核心优势

  * 统一网关

实现所有请求的接收、阻断、转发等功能,井识别当前状态对用户进行访问阻断、身份认证、防护识别、鉴权、访问转发等。

  * 身份中心

管理用户身份 ,对用户身份进行认证(多维认证,含密码认证、二维码认证、语音/指纹/人脸等生物特征认证等)。

  * 可信任验证

设立通用可信任验证或应用特定可信任认证,支持IP、浏览器、设备信息等环境可信任认证,支持验证码、滑块等行为可信任验证。

  * 动态权限管理

根据用户访问的目的地将应用的访问路径进行动态转换,转换后的临时请求地址开放给用户授权。在网关请求转发时进行鉴权通过后转发。

  * 动态访问控制

根据用户访问的目的地、请求的环境。认证的情况等进行动态授权,并支持动态鉴权。
