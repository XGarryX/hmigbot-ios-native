### 提供商介绍

北京合力云通科技有限公司成立于2015年,专注于A/B测试、个性化、灰度发布、智能推荐等系统的开发和服务。公司的“云眼”产品,是国内领先的决策优化系统系统,完美支持AB测试、个性化、灰度发布等功能特性。公司还提供决策优化、体验优化、转化率优化等解决方案和咨询服务。

### 核心优势

  * 支持个性化

通过假设、试验、分析和改进的闭环,提高运营能力。根据访客的地域、性别、年龄、设备、购物习惯、购买历史等,提供个性的产品推荐。

  * 可视化编辑

可视化编辑支持所见即所得(WYSIWYG),界面修改非技术人员即可完成,并可在线即时发布,切实降低App运营技术难度,节省成本,提高AB测试的效率和效果!

  * 智能采集

DK能够智能采集用户行为数据,免除手工埋点等繁琐工作,提高A/B测试实施效率,降低开发、测试和维护成本。

  * 大数据量化

采用大数据挖掘技术,对用户属性和行为特征,进行统计分析,科学准确确定AB测试胜出版本,并找出差异原因。全面、准确评估广告渠道、广告创意和关键词等的效果,确定更优的广告投放方案。
