### SDK介绍

热力引擎SDK面向App、网站、小程序等各平台提供归因分析、数据统计、用户行为分析能力,助力开发者完成渠道效果统计、广告投放分析与产品数据运营。

### 提供商介绍

广州汇量网络科技股份有限公司(Mobvista)成立于 2013年3月,是一个全球性技术平台,致力于推动数字时代的全球商业增长。凭借创新技术产品、全球化网络以及本地化服务能力,汇量科技为95个国家的7000多个活跃的应用开发者提供包括移动营销、统计归因、创意自动化、流量变现、云架构成本优化等产品和服务。日均触及超过9亿个独立移动设备,覆盖200多个国家和地区。Mobvista于2021年发布全域营销云产品矩阵品牌热力引擎,由旗下子公司汇量云(北京)科技有限公司负责主要运营。

### 核心优势

  * 开放性

基于插件化设计思想,对数据采集、存储、上报过程进行高度抽象,各模块具备极强的开放性。如属性插件化能力,基于该能力,可对上报数据进行任意新增、删除、修改;如加密插件化能力,基于该能力,可对上报数据进行自定义加解密,满足不同业务场景的诉求。

  * 多样性

涵盖了各种不同的功能点,包括但不限于控件点击、页面浏览、App启动退出、事件时长、崩溃采集、App与H5打通,满足不同集成方不同业务需要。

  * 易用性

提供详细的说明文档,含集成使用步骤和示例代码,帮助开发人员快速上手,短时间内实现功能。

  * 稳定性

经过严格的测试和优化,包括但不限于多轮次Code Review、高覆盖率的单元测试、黑白盒测试等,保证了SDK的稳定性和可靠性,确保集成方的业务不受影响。
