### SDK介绍

火山引擎增长营销套件SDK提供多种埋点形式,采集App、网站、小程序等各平台数据,并通过API聚合跨端、跨触点、用户全生命周期的数据,实现对用户的全面洞察。

### 提供商介绍

火山引擎是字节跳动旗下的云服务平台, 将字节跳动快速发展过程中积累的增长方法、技术能力和工具开放给外部企业,提供云基础、视频与内容分发、数智平台VeDI、 人工智能、开发与运维等服务,帮助企业在数字化升级中实现持续增长。

### 核心优势

增长营销套件SDK采集功能灵活、运行稳定,开发者可以根据采集需求自行设计并上报埋点,配备devtools工具,该工具帮助您对埋点内容和格式进行检查,提供了实时事件查看、实时接入状态查看、实时日志查看、实时网络请求查看等功能,工具不会收集个人信息,开发者可根据需要使用,提升埋点开发效率。

  * 功能丰富

支持自定义埋点、应用启动/退出统计、用户标识、用户属性、AB 实验分流、实时埋点验证、崩溃采集、请求加密等。

  * 可视化调试

可以通过Devtools可视化调试工具完成埋点产生到上报的流程验证,包括 SDK 接入状态检测,网络请求抓包等功能。

  * 数据安全

请求上报支持火山默认加密、国密加密以及自定义加密等。
