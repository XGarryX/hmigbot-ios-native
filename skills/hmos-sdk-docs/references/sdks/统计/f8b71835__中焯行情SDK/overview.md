### SDK介绍

tztzfhqdatasdk SDK ,是一个提供市场搜索、报价、分时、K线,明细,LV2(逐笔明细,分笔明细,分量)数据,行情主推,期权,板块/个股列表据等行情数据接口。。本库基于鸿蒙操作系统进行适配,使其可以运行在 HarmonyOS中,并沿用其现有用法和特性。
