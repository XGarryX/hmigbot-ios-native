### SDK介绍

个推用户运营SDK ,是一个融合数据采集、分析、洞察、圈人、运营计划于一体的数据服务产品,通过 SDK 进行用户行为埋点采集,经过数据的清洗、过滤组合后在平台侧实现用户数据的多维分析和洞察。 

### 提供商介绍

每日互动股份有限公司(个推)成立于2010年,是专业的数据智能服务商,致力于用数据让产业更智能。

公司最早以提供消息推送技术和服务起家,面向开发者提供专业的手机消息推送解决方案“个推消息推送SDK”,是国内推送领域的领跑者。同时,公司围绕“让数好用 把数用好”,推出了个推用户运营平台,帮助客户把数据用起来并沉淀数据资产,高效驱动客户全链路智慧化运营。多年来,公司不断丰富开发者服务产品能力,已经服务了数十万APP客户,SDK累计安装量突破1050亿,入选“中国互联网综合实力百强”。

### 核心优势

  * 海量端外标签 
    * 100+基础标签:性别、年龄、职业、兴趣
    * 100+行业标签:游戏、影音、育儿、健康
    * 100+线下行为特征:公共设施、餐饮、休闲
  * 行业经验赋能标签体系搭建 

提供丰富的标签规则搭建能力及行业模板标签能力,快速将复杂的用户行为数据转化为有业务含义的标签,降低运营人员的使用难度和专业度要求。 

  * 灵活易用 

基础看板、事件分析、基础画像能力满足运营人员的日常分析需求,简单易上手;自定义看板、多维度交叉分析和自定义画像维度等能力满足高阶运营的深入分析诉求。 

  * 推送打通 

精细化分析和洞察后可圈选目标用户群,将目标用户群通过个推推送进行定向运营,查看后效数据,无需对接多个平台。
