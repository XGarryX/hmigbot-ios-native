### SDK介绍

思迪信息理财商城鸿蒙 SDK(@thinkive/tk-harmony-mall)是面向金融机构 App 的理财商城 Web 容器,支持以 TKMallWeb 组件、路由或 Navigation 方式加载理财商城 H5 页面,并提供登录、登出、分享等代理事件注册与回调能力,便于宿主 App 与商城 H5 协同完成用户态与业务跳转。

SDK 与思迪理财商城 V6 大众理财能力配套,可承载首页运营、公募专区、公募投顾、收益凭证、个人中心(持仓、自选、足迹)、理财工具(理财日历、定投计算器、基金对比/诊断)等业务场景;机构通过标准集成文档完成 oh-package 引用、框架初始化与权限配置后即可接入。

### 核心优势

理财商城一站式接入  
       将理财商城 H5 与导航、状态栏、安全区、返回栈等能力统一封装,降低多家机构重复建设商城容器的成本,支持与思迪理财商城 V6 后端及 H5 标准对接。

灵活的打开方式与页面参数  
       支持组件集成、TKMallSDK.openWebPage 路由及 Navigation 栈打开;可配置全屏、标题栏、TabBar 嵌入、URL 编码、自定义 UserAgent 等,适配不同宿主 App 布局。  
  
代理事件扩展机制

       通过 registerDelegateEvent 处理登录、登出、分享及自定义事件,onDelegateEventBack 将结果回传商城 H5,便于与宿主账户体系、分享渠道打通。  
  
面向鸿蒙生态的适配

       基于 HarmonyOS NEXT 开发,配合 tk-harmony-base 框架与 useNormalizedOHMUrl 配置,适配机构鸿蒙应用工程规范。  
  
合规可控与最小权限

       默认仅申请网络相关系统权限(INTERNET、GET_NETWORK_INFO、GET_WIFI_INFO),配合隐私政策与合规使用指南,满足理财业务知情同意与最小必要原则。
