### 核心优势

  * 广泛应用于多元金融领域

      已广泛应用于证券、银行、信托、基金、期货等金融领域,主要用于视频见证、远程核身、理财双录、视频客服等场景,为金融机构提供客户自助和见证类业务办理的支持。

  *    完全适配非信创和信创服务

     TChat SDK已完全适配信创服务器,优化支持服务端信创改造目标,同时也完全兼容非信创服务,确保业务系统的顺畅运行、并轨运行。

  *    流畅且低消耗的通信体验

      支持音频预处理技术,如回声消除、噪音抑制、语音增益、静音检测,以及抗丢包策略,如动态码率控制、自动重传请求、前向纠错编码、丢包隐藏技术,以提供流畅且低消耗的通信体验。

  *    支持多种通信模式

      支持一对一、一对多、多对多、呼叫模式等多种模式的音视频交互。

  *    提供标准能力和运行机制

      信令数据传输通道、语音播报指令、语音识别指令、视频画面快速抓拍、多种视频录制模式、会话维持与恢复、网络异常提示与切换、异常日志记录与上报等。

  *     安全自主可控

      适配国产芯片,支持国密算法,适配国产服务器及操作系统,具体已支持鲲鹏的ARM架构和海光X86架构CPU版本,支持麒麟操作系统。
