# **聚典数据开放平台使用指南** 

在华为生态市场购买产品后,请前往 https://www.jdapi.com/ 进行账号的注册与使用。 

## **01 注册账号** 

前往 https://www.jdapi.com/ 进行账号的注册 

## **02 创建应用** 

登陆后,在网页右上角点击前往控制台 

在 “ 客户端管理 ” 中新建应用 

### 根据客户端的情况填写信息 

## **03 获取 SDK 和 Token** 

审核通过后,前往控制台应用管理的详情中查看相关密钥 

## **04 试运行调用** 

查看 SDK 相关文档 ( https://docs.jdapi.com/docs/sdk-intro/harmony ),按照文档上的说明进行调 用。
