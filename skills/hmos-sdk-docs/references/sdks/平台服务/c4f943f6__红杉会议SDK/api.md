## 前言 

本文主要讲述如何在 HarmonyOS 平台中使用给定的 API 接口,来连接、登录、新建和加入红杉通 视频会议 / 聊天系统。 

本文读者主要是给那些需要在 HarmonyOS APP 中集成红杉通视频会议 / 聊天功能的开发者。 

## 编译环境 

Open Harmony API 版本 : 5.0.2 ( 14 ) 

Dev eco 版本 : 5.0.2 

## 主要接口说明 

**1. joinConf (funcName: string, userId: number, confId: string,** 

**confPwd: string, joinName: string,** 

**confType: number, role: number,** 

**siteUrl: string, InviteUrl?: string)** ; 

- 功能描述 

- 加入会议。 

- 输入参数说明 

- String funcName :加会方法, joinConf- 参会者加入会议; startConf- 主持人加入会议 

- Int userId :用户 Id ,如果空,传 0 。 

- String confId : 会议号。 

**3** / **4** 

- String confPwd :会议密码 

- String joinName :参会昵称 

- int confType: 会议类型,目前仅有固定视频会议 默认为 2 。 

- int role: 参会角色,设置为 0 代表主持人,设置为 1 代表参加者。 

- Url: 会议服务器地址。 

- InviteUrl :会议中展示外部邀请页面,如不传,不显示邀请按钮。 

- 返回值说明 

   - 无 

- 调用示例 

   - 无
