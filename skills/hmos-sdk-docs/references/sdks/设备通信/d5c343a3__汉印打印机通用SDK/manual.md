## 一 、接入包作用 

提供适用于鸿蒙平台接口,使客户能够通过调用我方提供的鸿蒙 API将我们的打印机接入到 软件系统中。通过调用我们提供的接口,客户可以实现打印机与软件系统的无缝对接。 

### 二、机型支持范围 

|编号|指令集|固件版本|
|---|---|---|
|`01`|CPCL|所有版本|
|`02`|ESC|所有版本|
|`03`|TSPL|所有版本|
|`04`|ZPL|所有版本|

#### 注:其他指令集或支持型号范围外固件版本的设备暂不支持。
