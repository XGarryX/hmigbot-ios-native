# SDK介绍

飞天诚信蓝牙Key SDK,是面向鸿蒙生态设备的蓝牙身份认证与数据加密开发工具包,核心目标是让鸿蒙手机快速对接合规蓝牙 Key 硬件,实现安全、便捷的身份认证、数据签名 / 加密等功能,适用于企业办公、金融支付、政务服务、区块链等需要高安全级别的场景。

# 核心优势

飞天诚信蓝牙Key的核心优势,深度适配、金融级安全防护、极致使用体验、全场景灵活拓展四大维度,既解决传统蓝牙Key 的兼容性痛点,又依托鸿蒙特性实现安全与便捷的双重升级,具体如下:

深度适配:全面适配华为全系列鸿蒙手机及第三方鸿蒙设备,无需额外适配不同机型的蓝牙协议差异。

金融级安全防护,合规与隐私双重保障:私钥存储在蓝牙Key硬件芯片中,SDK 仅负责指令传输不触碰密钥,从根源杜绝泄露风险;支持国密算法(SM2/SM3/SM4)与国际算法(RSA/ECC/AES),满足等保三级、金融支付、政务合规等高标准安全要求;叠加HarmonyOS安全权限管控(需明确申请蓝牙通信权限),蓝牙传输数据全程加密,防范窃听、篡改等攻击,适配双因素认证(2FA)进一步提升安全等级。

极致便捷体验,操作与集成效率双高:无需依赖USB接口,靠近鸿蒙手机即可快速蓝牙配对、自动重连,摆脱插拔繁琐。
