### SDK介绍

PDBox SDK是为鸿蒙电脑连接与兼容多种外设设计的智能适配器。它超越了传统扩展坞的多接口扩展功能,通过智能协议转换与硬件抽象层技术,实现存量外设的“即插即用”与“南向一多”。

### 核心优势

PDBox SDK通过鸿蒙DDK外设驱动框架技术聚合政务领域各品类外设,如:

身份证读卡器、高拍仪、热敏凭条打印机、指纹仪、双目摄像头,

方便开发者快速调用SDK驱动外设能力

在深圳罗湖政务服务中心的鸿蒙柜面窗口《深圳市一窗综合服务受理平台-深圳市罗湖区政务服务中心》平台,
