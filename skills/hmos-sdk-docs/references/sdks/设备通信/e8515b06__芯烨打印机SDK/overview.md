### SDK介绍

本SDK是为鸿蒙应用量身打造的一款高性能、多协议集成的打印机开发套件。它兼容鸿蒙系统,提供了统一且简洁的ArkTS API,使开发者能够轻松地在鸿蒙应用中集成打印功能,并支持ESC/POS、TSPL主流打印机指令集,实现对各类打印设备(如票据打印机、标签打印机、家用打印机等)的广泛兼容和高效控制

### 提供商介绍

珠海芯烨电子科技有限公司是一家集研发、生产、销售、服务于一体的国际化打印机企业, 主营热敏票据打印机、标签打印机、 条码打印机、RFID打印机、便携打印机、嵌入式打印机、个人/家庭智能打印机、半导体精密制造及相关机芯核心零部件产品,是国内该行业领域极具竞争力的专业化、规模化企业,并致力于成为全球领域的打印机产品制造商与服务商。
