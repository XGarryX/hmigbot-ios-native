### SDK介绍

遥控精灵红外码库SDK,使用SDK可以接入遥控精灵APP的红外遥控码库,访问采用红外遥控技术家电的红外遥控码,包括“空调、电视、机顶盒、互联网盒子、投影仪、风扇、DVD、热水器、音响/功放、单反、空气净化器、开关、扫地机器人、电暖器、加湿器、窗帘、晾衣架、足浴盆、智能马桶”等。本库基于鸿蒙操作系统进行适配,使其可以运行在 HarmonyOS中。

  * 遥控码匹配 API
  * 遥控码下载API
  * 下载的空调码采用格式文件输出,需要本地解码
  * 下载的其他遥控码采用“载波频率+电平微秒”的明码格式输出,无需本地解码

### 提供商介绍

恬家遥控精灵是恬家(上海)信息科技有限公司开发的手机配件及其APP的统称,是将手机/Pad变身万能红外遥控器的工具,最早版本于2012年3月发布。遥控精灵由恬家(上海)信息科技有限公司开发,该公司是国内较早开展手机内置红外学习方案研究的企业,能提供硬件+驱动+APP+码库+EPG端到端解决方案,还为多家手机厂商提供技术支持。遥控精灵APP本身为免费软件,最新版本更新至2026年。恬家有系统化的码库整理机制,确保各种新家电红外码的及时收纳。
