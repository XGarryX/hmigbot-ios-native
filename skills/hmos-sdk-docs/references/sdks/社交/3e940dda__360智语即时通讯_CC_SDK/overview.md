### SDK介绍

360智语即时通讯 CC-SDK 是一款面向企业移动办公和协同沟通场景的即时通讯 SDK,支持单聊、群聊、会话列表、文本消息、图片消息、语音消息、视频消息、文件消息、Push通知、消息阅读状态等能力。借助SDK,开发者可在宿主 App 中快速集成企业 IM、消息收发、推送通知等常见协同功能。

  * IM功能
  * 会话列表
  * 单聊、群聊
  * 消息收发与阅读状态 Push通知

### 提供商介绍

上海三六零智语科技有限公司是面向企业办公协同和即时通讯场景的技术服务提供商,致力于为企业客户提供稳定、安全、易集成的移动办公与沟通协同解决方案。

公司围绕企业即时通讯、消息推送、账号体系对接等场景,沉淀了完整的 SDK 产品能力和工程实践经验。通过 CC-SDK(智语 SDK),开发者可以在已有 App 中快速接入企业 IM、推送通知等能力,降低企业协同办公功能的自研成本,提升移动端办公产品的交付效率和用户体验。

### 核心优势

能力完整:CC-SDK 覆盖企业移动办公中的核心协同场景,支持单聊、群聊、会话列表、文本消息、图片消息、语音消息、视频消息、文件消息、卡片消息、引用消息、Push通知、消息阅读状态、消息撤回、消息加密、云消息漫游等能力,可帮助宿主 App 快速构建完整的企业沟通与协同功能。

集成灵活:SDK 同时提供多种集成方式。开发者既可以快速集成SDK,也可以根据业务需求灵活配置,适配不同业务场景和产品结构。

支持定制扩展:SDK 提供一定的 UI 样式调整能力,支持标题栏颜色、图标颜色、状态栏色系、会话列表样式等配置,同时支持首页加号菜单和聊天消息长按菜单扩展,便于宿主 App 与自身产品体验保持一致。
