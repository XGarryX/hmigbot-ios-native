### SDK介绍

网易云信 IMSDK(NetEase Instant Messaging SDK,NIM SDK)为 HarmonyOS 环境 SDK,提供完善的即时通信功能开发能力,屏蔽其内部复杂细节,对外提供较为简洁的 API 接口,方便您快速集成即时通信功能。

IM HarmonyOS SDK 提供的功能包括登录、会话、消息、群组、用戶、好友、存储服务、推送、自定义通知等。

### 提供商介绍

网易云信,集网易 27 年技术打造的融合通信与云原生PaaS 服务专家。为开发者提供融合通信与云原生核心产品及解决方案,包含 IM 即时通讯、视频云、短信,及轻舟微服务、中间件 PaaS 等。 目前,融合通信已接入 180 万企业开发者,全球注册应用数超 61 万,累计覆盖智能终端 SDK 数超 246 亿,月均消息量 2000+ 亿条居行业首位。
