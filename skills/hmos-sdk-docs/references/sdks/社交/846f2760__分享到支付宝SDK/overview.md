### SDK介绍

分享到支付宝是指第三方移动应用通过接入该功能,让用户可以分享图片、网页至支付宝。

分享功能已向全体开发者开放,开发者在支付宝开放平台账号下申请 App 并通过审核后,将对应 SDK 集成至开发者移动端应用中,通过调用该接口即可实现分享到支付宝。

### 提供商介绍

蚂蚁集团旗下支付宝,是全球领先的数字支付开发平台与服务业数字化开发平台,已经服务10亿用户。我们面向消费者、商家提供便捷、安全的数字支付服务,面向合作伙伴持续开发技术、产品,助力实现数字化升级。

### 核心优势

增加应用传播:通过分享给支付宝好友,商家的移动应用不但可以直接触达支付宝用户,还可通过支付宝进行快速社交传播。

无障碍衔接交易,提升转化率:用户可对分享到支付宝的商品或内容无障碍进行购买支付,有效提升转化率。
