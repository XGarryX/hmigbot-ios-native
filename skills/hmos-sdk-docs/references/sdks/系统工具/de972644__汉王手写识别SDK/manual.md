# 1. 简介 

汉王嵌入式手写SDK 产品为客户提供快速集成与部署能力,本文档的目 的是帮助开发者使用汉王手写输入产品的SDK 进行手写输入的应用开发。通 过介绍SDK 的组织结构和接口,使应用软件开发人员能正确调用API 接口, 实现手写输入。 

# 2. 功能描述 

### 2.1. 支持语言 

中文简体、中文繁体、日文、韩文、英文、法文、德文、葡萄牙文、意大 利文、西班牙文、匈牙利文、荷兰文、芬兰文、瑞典文、丹麦文、冰岛文、波 兰文、捷克文、斯洛文尼亚文、爱尔兰文、土耳其文、俄文、乌克兰文、印度 尼西亚文、马来西亚文、罗马尼亚文等。 

### 2.2. 支持识别模式 

### 2.2.1. 行识别 

专注于在手写笔迹中对整行的文字或字符进行识别,同时适用于连笔书写 的场景。根据预处理的词汇表以及字符间的上下文关系,来提高识别的精准 度。通常用于处理连续书写的句子,合理的处理字符之间的自然连接与间距的 问题。

### 3.1. 系统结构 

手写输入引擎采用分层结构:分别为字典层、引擎层,SDK接口层和应用 层,其中应用层为客户实现。如下图所示: 

图1. 汉王手写输入系统结构 

### 3.1.1. 应用层 

- 开发者需要在这一层处理手写输入的基本输入/输出,获得手写轨迹信 

- 息,显示候选,获得用户命令等。界面处理需要开发者来实现。 

### 3.1.2. SDK 接口层 

这一层为对开发者的接口,包括SDK 的配置,宏定义,接口声明。开发 者可以通过调用相应的SDK接口来实现手写识别功能。 

### 3.1.3. 手写输入引擎 

该层连接了外部接口和底层词典,负责识别输入的笔迹信息并进行识别。
