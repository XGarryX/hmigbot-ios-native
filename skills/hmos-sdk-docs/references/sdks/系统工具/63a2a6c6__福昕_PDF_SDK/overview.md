### SDK介绍

福昕 PDF HarmonyOS SDK 是一款为 HarmonyOS Next 平台量身定制的软件开发工具包,旨在帮助开发者快速构建高性能、跨设备的 HarmonyOS PDF 应用程序。SDK 兼容 福昕 通用SDK 的底层接口,并在此基础上提供了丰富的扩展功能,显著提升了开发效率和用户体验。

  * ViewerCtrl

提供了灵活的视图切换、显示适配、页面操作等功能,满足各种复杂的界面展示需求

支持多种交互方式,如缩放、平移、旋转,页面跳转等,增强用户体验

提供丰富的回调接口,方便开发者自定义业务逻辑

  * UI Extension

提供了大纲、表单填写、视图设置等高级 UI 组件,简化了复杂界面的开发。

支持 More 菜单,方便用户快速访问常用功能。
