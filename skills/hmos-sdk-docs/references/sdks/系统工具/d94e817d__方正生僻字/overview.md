### 提供商介绍

方正字库隶属于北京北大方正电子有限公司,起源于北京大学王选教授主持的“汉字信息处理系统748工程”,字款丰富、品质精良、适用面广,广泛应用于专业出版、印刷、包装、广告、互联网、操作系统、应用软件、硬件设备等领域。

方正电子是公安部指定的字库合作伙伴,“方正人口信息生僻字解决方案”是目前唯一可解决全国人名及地名生僻字问题的正式产品。全国公安人口信息管理系统、全国派出所综合信息管理系统、居民身份证制证系统、护照制证系统、港澳台居民居住证制证等系统都统一采用了方正人口信息生僻字解决方案,并由方正电子提供长期的售后服务保障。同时,方正生僻字还为建设银行、工商银行、中信银行、支付宝、中国银联等20余家金融客户提供生僻字解决方案。
