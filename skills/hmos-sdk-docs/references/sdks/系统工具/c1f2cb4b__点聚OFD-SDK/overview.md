### SDK介绍

"点聚SDK-OFD"是由北京点聚有限公司提供的一个基于版式文档(OFD/PDF/AIP)上的HarmonyOS SDK工具包,引入该SDK包后可以加载显示版式文档,在版式文档上批阅等多项功能,功能概要如下:

-加载PDF/OFD/AIP版式文档;

-在文档上添加文字批注、手写批注、涂鸦、插图、数字签名、盖章;

-修改和删除文字/手写/图片;移动文字/手写/图片位置;

-添加高亮、下划线、删除线;

-文件合并:多个OFD/PDF/AIP文档合并为一个新的长文档;

-文档格式转换:OFD、PDF、AIP三种文件格式的转换;

### 核心优势

"点聚OFD-SDK"围绕电子签章、OFD 版式、数字证书三大可信能力底座,为第三方业务系统提供全流程、模块化、低耦合的可信接口服务。

"点聚OFD-SDK"将版式与签章的原生融合,无需额外集成第三方签章组件。SDK 内嵌电子签章核心能力,可直接调用完成 OFD/PDF 的盖章、验章;支持电子印章、骑缝章、手写签名、文字/图片水印,支持签章有效性验证,严格遵循《GB/T 33190-2016》和《GB/T 33481-2016 党政机关电子印章应用规范》。

"点聚OFD-SDK"采用模块化设计,极大降低集成门槛。提供标准 API 为第三方业务系统增加 OFD 处理功能;模块化架构,易于与 OA、ERP、CRM、电子公文系统等第三方业务系统无缝集成;提供完善的接口手册和 Demo 工程,应用开发人员只需关注业务处置,大大缩短上线周期。

"点聚OFD-SDK"还原真实纸笔书写体验,通过多项自主研发算法,实现了电子文档上的高精度、高仿真手写效果。手写笔迹细腻真实,支持压感,用力越大笔迹越粗,用力越小笔迹越细,完全模拟真实书写时的力度变化;笔迹带有自然的粗细变化和笔锋转折;根据书写速度动态调整笔迹形态,速度快时线条流畅,速度慢时墨迹饱满;彻底消除传统电子手写常见的锯齿和阶梯感,笔迹边缘圆润流畅;手写笔迹以矢量数据记录,无论放大多少倍均保持清晰,不损失细节。
