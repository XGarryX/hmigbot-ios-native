### SDK介绍

该组件为鸿蒙端侧组件,通过与科蓝移动开发平台MADP无缝对接,为可高效复用业务H5资产、实现业务三端统一,推出的鸿蒙原生开发框架。可为移动金融鸿蒙生态(HarmonyOS+OpenHarmony)开发、测试、运营提供全生命周期的解决方案,支持元服务和原生APP,能够降低接入门槛,减少开发成本和提供开发交付效率,帮助企业快速上线符合金融资金交易级鸿蒙原生金融服务。

### 提供商介绍

科蓝软件是中国领军的金融数字化咨询及解决方案服务商,华为首批鸿蒙生态合作伙伴、首批HarmonyOS开发服务商、华为鸿蒙生态市场服务商、OpenHarmony金融支付专委会成员、OpenHarmony生态创新示范单位。向金融行业提供鸿蒙原生SDK组件、鸿蒙原生应用开发、鸿蒙化迁移、鸿蒙元服务开发一体化解决方案服务。

### 核心优势

  * 高效复用,无缝接入已有MADP平台,实现已有资产高效复用。
  * 安全可靠,遵循JR-T 0092-2019 《移动金融客户端应用软件安全管理规范》规范。
  * 组件丰富,通讯报文加解密、本地安全存储、资源加解密、web容器、UI等组件库。
