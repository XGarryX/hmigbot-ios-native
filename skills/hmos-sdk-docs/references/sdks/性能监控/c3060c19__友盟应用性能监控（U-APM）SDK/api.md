# **APM** 集成文档 

- 1、获取 SDK安装 SDK 

在 DevEco Studio 5.x 版本的 IDE 中,从顶部菜单 Tools->Partner SDK 的Analysis 分 类中找到【友盟 common SDK】点击 install、【友盟统计分析(U-APP)】的包,点击 install 按钮、从顶部菜单 Tools->Partner SDK 的 性能监控 分类【友盟应用性能监控 (U-APM))】点击 install 按钮。 

注意:应用性能监控的 SDK 接入需要将上述 3 个 SDK 均引入后才可使用
