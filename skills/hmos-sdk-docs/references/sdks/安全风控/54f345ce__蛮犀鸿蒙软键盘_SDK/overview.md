### 核心优势

  * 双层结构:ArkTS + Native 组合实现,便于展示与后续增强
  * 随机键位:每次会话可重新排列键盘布局
  * 去标识化:输入过程仅显示掩码字符

  * 模块化:代码已按配置、模型、核心算法、桥接、服务、UI 分层
  * 可交互 Demo:当前演示包已支持真实点击输入、模式切换、删除、清空与提交封装
