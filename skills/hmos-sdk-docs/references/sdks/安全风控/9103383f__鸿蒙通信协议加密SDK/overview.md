### SDK介绍

鸿蒙通信协议加密SDK是360自主研发的高安全性通信协议数据保护方案。用户在客户端、服务器分别嵌入通信协议加密SDK,通信时数据在客户端进行加密后开始传输,服务器端进行解密,保证传输数据的安全性。
