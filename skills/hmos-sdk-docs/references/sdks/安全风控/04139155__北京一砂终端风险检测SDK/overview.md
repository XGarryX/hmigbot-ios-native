### SDK介绍

终端风险检测SDK包括从TEE可信环境获取到的安全地理位置、可信设备证明、设备健康检测、恶意 URL 检测能力等终端风险识别能力; 

  * 可信地理位置:在系统中获取GPS、WIFI 以及网络地理位置等位置信息,并直接在TEE可信环境里完成安全证明,已确保提取地理位置是没有被篡改的。 
  * 可信设备证明:提供设备真实性证明和应用身份证明的能力,该能力基于可信执行环境TEE的密码算法、证书链实现对业务请求是否来自真实设备和合法应用的校验。 
  * 设备健康检查:基于可信执行环境 TEE 提供系统完整性检测结果,可以提供设备被ROOT、设备系统被解锁,刷机风险检测、模拟器及设备被篡改风险标签。 
  * 恶意URL检测能力:用户访问网址时,判断用户访问的 URL 是否为恶意网址,并将检测结果返回给您的应用,包括:正常、钓鱼风险、木马风险、其他风险。

### 提供商介绍

北京一砂是一家互联网身份认证和安全产品服务商,主要提供基于IIFAA(互联网可信认证联盟)标准的可信终端相关产品和服务,致力于让智能终端都有可信的储存计算空间。北京一砂基于终端安全、生物识别、分布式等技术,推出了全系列可信终端产品及解决方案,覆盖超过16亿智能设备。
