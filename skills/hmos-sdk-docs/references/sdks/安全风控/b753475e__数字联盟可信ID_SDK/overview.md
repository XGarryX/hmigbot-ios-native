### 提供商介绍

北京数字联盟网络科技有限公司(简称“数盟”)是提供移动终端可信ID技术并获得中关村高新技术企业资质认可的技术驱动型公司,可信ID技术具有自主知识产权及著作权,数盟自主研发的“识别虚假移动终端的方法和装置”已获得国家知识产权局专利。

数盟可信ID能够实时识别移动终端有效性和唯一性,实现设备ID实时生成、获取、设备状态实时查询、精准识别虚拟机、详细数据的对接、关联等功能。客户涵盖金融、视频直播、生活旅游、电商、社交等众多领域。
