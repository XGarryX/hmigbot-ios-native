### SDK介绍

DigitalKeylibrary是一个运行在鸿蒙系统中的基于蓝牙功能开发的,通过手机完成车辆连接,车辆解锁,车辆信息获取等操作。 功能包含库初始化、蓝牙初始化、数字钥匙蓝牙连接、手机与硬件通信的双向认证、控车及通信数据加密、数字钥匙激活、数字钥匙下载、数字钥匙分享、数字钥匙撤销、同步数字钥匙状态、注销数字钥匙、清空数据、销毁缓存数据等功能。
