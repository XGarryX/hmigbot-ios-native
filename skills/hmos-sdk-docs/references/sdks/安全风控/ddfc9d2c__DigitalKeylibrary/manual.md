# 1. 前言 

## 1.1. 文档目的 

本文档旨在详细说明汽车数字钥匙系统移动端SDK(以下简称“SDK”)的接入、配置、功能 调用及常见问题处理,帮助开发者快速完成SDK 集成,实现汽车数字钥匙的移动端管控功能, 包括钥匙绑定、解锁/上锁、远程控制、钥匙分享等核心操作,提升开发效率并保障功能稳 定运行。 

## 1.2. 适用范围 

本指南适用于所有需要集成本SDK 的鸿蒙系统移动端应用开发者,涵盖SDK 接入前准备、集 成过程、功能调试等全流程,要求开发者具备基础的鸿蒙应用开发能力,熟悉Java/JS 开发 语言及鸿蒙应用开发框架。 

# 2. **SDK** 概述 

## 2.1. 功能介绍 

本SDK 专为鸿蒙系统移动端应用设计,聚焦汽车数字钥匙核心功能,提供以下核心能力,全 面适配鸿蒙生态应用开发需求,助力开发者快速构建合规、安全的数字钥匙应用: 钥匙管理:支持数字钥匙的激活、下载、删除、钥匙状态查询等功能。 钥匙分享:支持将数字钥匙分享给其他用户,可设置分享权限(如临时使用、永久使用)及 有效期。 

车辆管理:可通过SDK 实现车辆的远程控车,实现车辆远程解锁/上锁、开关车窗。 

## 2.2. 环境要求 

## 2.2.1 开发环境 

开发工具:DevEco Studio 6.0.0 及以上版本。 

开发语言:ArkTS 

1 

系统版本:鸿蒙OS 5.0 及以上版本。 

## 2.2.2 运行环境 

移动端设备:支持鸿蒙OS 5.0 及以上版本的智能手机,需具备蓝牙5.0 及以上、网络连接 (4G/5G/Wi-Fi)。 

网络要求:确保设备能够正常访问互联网,用于获取钥匙状态,进行钥匙的激活下载。 

# 3. **SDK** 接入准备 

## 3.1. 开发环境配置 

1. 安装DevEco Studio 6.0.0 及以上版本,配置鸿蒙OS 开发环境(包括SDK、模拟器、调 试工具)。 

2. 将下载的SDK 安装包导入开发项目,配置SDK 依赖。 

3. 将签名证书导入项目,确保应用能够正常调试和打包,符合鸿蒙应用安全加密要求。 

## 3.2. 前提条件 

1. 开发者已完成应用的基础开发,具备完整的用户界面及交互逻辑。 

2. 移动端设备已开启蓝牙、网络连接功能。 

3. 开发者已熟悉鸿蒙应用权限申请流程,能够正确申请SDK 所需的系统权限(如蓝牙、网 络、存储等),避免权限滥用导致的安全风险。

## 6.3. 测试验收 

开发者需完成以下测试场景,确保 SDK 功能正常、稳定,符合鸿蒙生态应用安全要求 及用户体验标准: 

1. 功能测试:验证钥匙下载、车辆控制、钥匙分享、状态查询等所有核心功能是否正常。 

2. 兼容性测试:在不同鸿蒙 OS 版本、不同品牌的移动端设备上测试,确保功能兼容。 

3. 稳定性测试:长时间运行 SDK,模拟频繁操作,检查是否出现崩溃、卡顿等问题。 

4. 安全测试:验证数据传输加密、权限控制、钥匙安全等是否符合要求,防止数据泄露 或篡改。 

# 7. 上线与维护 

## 7.1. 上线准备 

1. 关闭 SDK 调试模式,确保日志不泄露敏感信息。 

6 

2. 完成应用打包,使用合规的签名证书签名,符合鸿蒙应用上架要求。 

3. 在应用隐私政策中明确说明 SDK 收集、使用个人信息的情况,符合合规要求。 

4. 确保应用已获取所有必要权限,且权限申请符合鸿蒙系统规范。 

## 7.2. **SDK** 更新与维护 

1. 开发者需与 SDK 供应商及时联系,及时升级 SDK 版本,修复已知问题、适配新系 统版本及监管新规要求。 

2. 若 SDK 接口有变更,会提前在通知开发,开发者需根据变更说明调整应用代码,避 免影响功能正常使用。 

3. 遇到 SDK 相关问题,可联系技术支持人员获取帮助。
