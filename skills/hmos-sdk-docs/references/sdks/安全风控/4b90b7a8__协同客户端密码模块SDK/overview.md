### SDK介绍

协同客户端密码模块核心采用商密SM2/SM3/SM4/SM9算法,并兼容国际AES/DES/3DES/SHA/RSA等算法。集成协同签名、数字证书及GMSSL等密码能力,全面保障身份认证、网络及通信安全,应用及数据安全。构建合规、可信的终端安全体系,提供多元化、标准化的安全解决方案,精准满足各行业安全需求。

SDK管理

  * 密钥管理: 提供密钥管理能力,支持SM2和RSA类型密钥和对应算法等
  * 证书管理:证书整个生命周期管理,支持SM2和RSA证书等
  * 密钥运算:支持商密SM2/SM3/SM4/SM9算法,并兼容国际AES/DES/3DES/SHA/RSA等算法。集成协同签名能力。
  * 提供构建安全通道的能力,包括: 商密socket、商密https、商密axios,同时支持TLCP(国密)协议和TLS(国际)协议单双向,兼容系统API接口,与系统API保持一致
