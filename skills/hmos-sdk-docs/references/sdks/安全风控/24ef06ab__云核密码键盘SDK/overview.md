### 核心优势

  * 提供密码输入全流程安全防护,有效抵御输入环节恶意攻击,保障密码等敏感信息全程安全。
  * 采用内存密文存储、逐位加密及动态键值转换,结合键盘乱序布局与无按键状态显示,强力防截屏窃取。
  * 具备防重放、反调试、反注入、抗反汇编及防录屏等多重防护能力,实现一次一密安全提交。
  * 兼容场景广泛,既支持原生输入框保护,也支持 H5 桥接原生密码键盘进行安全输入。
  * 支持多种加密算法、加密格式变换及密码强度规则,可灵活满足不同业务安全加密需求。
