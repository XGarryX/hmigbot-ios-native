### SDK介绍

深圳CA协同签章密码模块是一款由深圳市电子商务安全证书管理有限公司自研,基于协同密码模块扩展的移动签章开发中间件,提供证书管理、PDF/OFD文档预览、签章及验章,支持坐标、骑缝章、关键字等方式签章,产品严格遵循国家密码管理局发布的GB/T 38540《信息安全技术安全电子签章密码技术规范》标准。

### 提供商介绍

深圳CA(全称“深圳市电子商务安全证书管理有限公司”)成立于2000年,是经国家工业与信息化部及国家密码管理局批准的权威认证机构,是国内首批获得跨境电子认证资质的认证机构,是平安集团金融生态圈成员企业。

作为国家级高新技术企业,深圳CA历来注重技术创新,目前已拥有20多项发明专利、120项软件著作权,以及10多项自主开发、自主版权的网络安全产品及解决方案,且建立了一支在国内网络安全和信息化领域技术研发、实践应用能力一流的专家团队和管理团队。
