### SDK介绍

基于手机终端可信环境TEE结合PKI技术,在TEE/SE中实现身份认证、数字签名和数据加密等功能,在可信显示界面(TUI)实现PIN码输入、交易信息回显和交易确认,达到“所见即所签”的效果。 

### 提供商介绍

北京一砂是一家互联网身份认证和安全产品服务商,主要提供基于IIFAA(互联网可信认证联盟)标准的身份认证相关产品和服务,致力于让智能设备都有可信的储存计算空间。北京一砂基于终端安全、生物识别、分布式计算等技术,推出了全系列可信身份认证产品及解决方案,覆盖超过16亿智能设备。 

### 核心优势 

  * 国产化

IFAA联盟是信通院、华为、蚂蚁等发起的产业联盟,标准自主可控;支持国密SM2/SM3/SM4算法;

  * 高安全

基于TEE环境实现密钥对生成,集合可信用户界面(TUI)支持所见即所签,整体方案等同于实体二代U盾;

  * 低成本

减少行里二代U盾的采购数量,手机盾按激活付费,并激活价格低于实体U盾采购价格;可复用现有电子认证CA系统,无需改造;

  * 体验好

与移动终端业务应用(APP)高度集成,用户零学习成本;

  * 平滑升级:在现有移动身份认证平台基础上升级手机端SDK和服务端模块即可支持手机盾功能;
