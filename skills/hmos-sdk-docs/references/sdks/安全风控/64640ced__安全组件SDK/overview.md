### SDK介绍

数犀安全组件是为HarmonyOS应用量身打造的企业级安全管控解决方案,提供多项核心安全能力,助力企业实现终端设备精细化管控与数据防泄漏。组件采用轻量化设计,支持快速集成与策略动态下发。

### 提供商介绍

北京数犀科技有限公司是一家面向钉钉、飞书、Microsoft365等平台提供身份连接、身份管理及应用集成服务的公司,致力于解决企业在数字化过程中遇到的身份、认证及应用集成问题。团队专注在企业身份认证、移动安全、零信任安全领域数十年,大部分成员来源于BlackBerry、KeeeWeee等公司。
