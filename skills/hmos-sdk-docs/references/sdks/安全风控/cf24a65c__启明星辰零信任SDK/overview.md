启明星辰零信任SDK是一个面向零信任架构的安全开发套件,本SDK聚焦数据安全与灵活身份验证,助力企业实现细粒度可信访问控制。本库基于HarmonyOS进行适配,使其可以运行在 HarmonyOS中,并沿用其现有用法和特性。
