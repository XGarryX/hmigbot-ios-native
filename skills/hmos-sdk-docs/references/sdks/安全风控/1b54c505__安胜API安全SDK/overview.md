### 核心优势

1、全方位的终端环境监测,识别异常终端

通过SDK在应用中运行的过程中,对应用运行环境数据进行采集分析,识别是否存在攻击者破坏运行环境而进一步发起攻击行为,如使用代理访问、模拟器等,

2、前后端结合识别异常业务访问行为

通过前端设备环境信息的采集,生成设备指纹信息,识别唯一设备,与后端服务进行结合,识别前端到后端访问过程中全链路的业务访问安全,发现异常业务访问行为。
