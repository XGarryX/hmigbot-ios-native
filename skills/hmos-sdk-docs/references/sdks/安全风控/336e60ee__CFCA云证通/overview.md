### SDK介绍

CFCA云证通是基于PKI技术体系、实现移动证书云签名的安全应用产品。可实现证书云端存储、本地签名和云端验签功能,使用自主研发的分离式密钥管理机制实现安全保护,按照标准化、安全性、先进性、可靠性、易用性五大原则设计,由CFCA对终端用户提供互联网公网服务。

### 提供商介绍

中金金融认证中心(CFCA)自1998年由中国人民银行牵头组建以来,已发展为集网络安全综合服务为一体的科技企业。经过二十多年的积累,CFCA不仅在信息安全领域成为重要基础设施,还推出了“云证通”等创新服务,以及密码组件产品,为用户提供了全方位的网络安全解决方案。

其中,密码组件产品采用先进的加密技术,保护用户数据的安全性和完整性,确保业务交易的真实性和不可否认性。它可广泛应用于各种系统和应用中,帮助用户构建安全可信的网络环境。

CFCA是最早通过WebTrust国际审计并获得主流根证书库认可的电子认证机构,是中国内地唯一获得LEI验证代理资格的机构。依托其雄厚的技术实力和多元化服务优势,CFCA将继续为用户提供更优质、更安全的网络安全服务,助力政府、金融机构、企业集团实现数字化转型和升级。

### 核心优势

  * 简单易用、方便集成

用户使用手机作为安全认证载体,只需拥有一张HKE证书,就可安全、便捷的使用数字签名服务,做到随时、随地、随签。

  * 跨渠道整合,兼容PC、小程序等应用场景

通过建立统一的签名服务,各个渠道如手机银行、网上银行乃至直销银行都可使用统一的签名服务,而不用建立单独的签名验证体系。

  * 第三方责任认定及举证

一方面,可以在发生业务纠纷时,提供有效的证据供司法举证。另一方面,可分担互联网创新业务带来的业务风险。

  * 安全性保障

云证通证书密钥分散生成及分散保护技术 ,云证通服务端和手机客户端各生成不同的用户证书私钥,各私钥之间无直接关系
