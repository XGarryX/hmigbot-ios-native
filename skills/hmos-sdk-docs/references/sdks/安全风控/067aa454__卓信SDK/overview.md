### SDK介绍

随着移动互联网行业对用户隐私和个人信息保护的逐渐重视,传统的设备唯一性标识(如IMEI)以及用户唯一性标识(如手机号码、IMSI)将不再适用。这给移动互联网行业,特别是流量反欺诈、消息推送等各个领域带来巨大的挑战。行业迫切需要一种跨终端、跨生态和操作系统解耦,兼顾数据安全、个人信息保护和产业发展需求的匿名标识元服务开展相关业务。针对上述情况,统一移动基础服务平台推出了移动互联网匿名标识元服务-卓信ID解决方案,上述标识元服务具备多次匿名机制、过期机制、受控机制,可在合法合规、保护用户权益的前提条件下,解决移动互联网行业痛点问题,以增强各企业在数字行业的竞争力,发挥数据的商业价值,为数字经济发展赋能。“统一移动基础服务平台”(Unified Mobile Service,UMS)是中国信息通信研究院联合中国互联网协会于2021年共同发起,致力于促进我国移动互联网生态自主创新,推动我国自主标准使用,发展自主可控的移动基础服务平台。卓信ID是统一移动基础服务平台核心基础服务之一。 

### 提供商介绍

中国互联网协会是由中国互联网行业及与互联网相关的企事业单位、社会组织自愿结成的全国性、行业性、非营利性社会组织(成立于2001年),参与制定互联网有关的国家标准和行业标准,维护国家网络与信息安全,保护公民的信息安全,是国内最权威的互联网管理服务机构之一。 

### 核心优势

  * 权威性

由中国信通院官方认证、打造,由信通院统一生成并管理。
