#### **1. 文档目的** 

本文档主要针对电子签名服务器软件(简称:TopESA)鸿蒙版 SDK 的接口功 能及集成使用进行介绍,方便开发者快速了解使用 SDK 相关功能。 

#### **2. 准备文件** 

hmtopnesa.har 

#### **3. 文件说明** 

库文件是 SDK 核心功能代码的实现,目前所支持的 cpu 架构有 'arm64-v8a','x86-64' 

#### **4. 环境配置** 

### 集成准备 

- 1.需要下载 DevEco Studio 5.0.0 及 5.0.0 以上版本进行集成 

- 2.在项目的 build-profile.json5 文件下配置兼容 sdk 版本为:5.0.0(12), 

   - "compatibleSdkVersion": "5.0.0(12)","useNormalizedOHMUrl": true 

3. 在 entry 的 module.json5 里面添加网络权限: "name": "ohos.permission.INTERNET"

### 集成 **sdk** 

- 1.将目标 har 文件,例如 hmtopnesa.har 文件,复制粘贴在工程的 entry/libs/目录 下。 

- 2.在 entry 目录下的 oh-package.json5 文件中添加以下代码: 

"hmtopmsa": "file:./libs/hmtopnesa.har" 

- 3.点击 rebuild 下的 Rebuild Project,对项目进行重新构建
