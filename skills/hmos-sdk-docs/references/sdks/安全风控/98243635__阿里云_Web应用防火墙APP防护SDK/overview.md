### SDK介绍

阿里云Web应用防火墙APP防护SDK是一款专为Web应用和API提供Bot流量管理的安全防护组件,构建于阿里云Web应用防火墙(WAF)基础能力之上,为业务提供实时线上Bot流量"识别-防护-管控-分析"能力,支持恶意爬虫检测、自动化脚本拦截、人机验证等业务场景。同时,借助Bot行为画像和智能策略引擎,帮助开发者快速识别和处置异常流量,保障业务安全与数据资产。

**智能Bot识别与精准流量管控**

结合WAF核心防护能力,Bot管理与Web安全防护形成协同联动
