### SDK介绍

微通新成国密SSL模块为用户提供国产密码算法的SSL通道加密防护功能,实现移动应用App与国密SSL网关建立国密算法(SM2)单向、双向SSL安全通道加密,可以支持国密算法SSL通道和国际算法SSL通道的智能切换,完成国密SSL通道的握手、随机数生成、密钥交换、服务端证书验证等功能,可以无障碍访问国密网关的服务端网站。支持国密标准的SSL协议证书,从而使不具备国密SSL能力的移动应用App支持国密SSL加密通道。微通新成国密SSL模块具备反调试、反注入、抗反汇编保护能力。
