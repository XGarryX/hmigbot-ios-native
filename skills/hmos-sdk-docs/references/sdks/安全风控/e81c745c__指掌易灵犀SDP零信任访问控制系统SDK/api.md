## **1** 概述 

指掌易 SafeLink 安全网关为企业应用提供了安全,高效,可扩展的网络接入方案,并 提供了包含上述服务的 SDK,旨在帮助企业 APP 客户端与服务器之间建立透明化的安全隧 道,且不影响应用开发的任何逻辑。 

### **1.1 SDK** 方法说明 

UUSdpClient 为 SDP 管理类唯一实例,SDP 操作所有方法都基于该管理类操作,以下 为关键方法说明。 

#### **1.1.1** 初始化 **init** 

|类名|UUSdpClient|
|---|---|
|方法|init(context: common.UIAbilityContext, sdpConfig: UUSdpConfig)|
|描述|初始化sdk需要的相关全局参数和上下文context|
|参数|params:Sdp Sdk初始化配置参数,UUSdpConfig类型参数如下: * 服务器地址必选项 host: string; * 服务器端口必选项 port: number; * 企业标识可选项 ec?: string; * 客户端唯一标识必选项32位字符串 cid?: string|
|返回|无|
|示例|let config: UUSdpConfig = { host: this._loginHost, port: this._loginPort, ec: this._loginEc, cid: this._cid } let context: common.UIAbilityContext =getContext(this)as common.UIAbilityContext;|
