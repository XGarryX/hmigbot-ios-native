### SDK介绍

屹通安全键盘SDK是面向 HarmonyOS 的自定义安全键盘 SDK,提供文本输入键盘、Web 场景键盘、数字/字母/符号/身份证/金额等多种键盘类型,支持按键乱序、输入加密、密文回调、统一解密、最大长度和金额小数位限制、按键音效、振动反馈、自定义键盘头、点击背景收起及防截屏配置,适用于账号、密码、证件号、金额等敏感输入场景。

### 提供商介绍

上海屹通信息科技发展有限公司,正式成立于2004年,是一家专注银行业应用软件开发与咨询服务的高新技术企业。公司总部设立于上海,研发中心位于合肥市,分支机构遍布于北京、天津、重庆、内蒙古、陕西、甘肃、河南、山东、四川、江苏、浙江、福建、广东等省市。目前为国内领先的互联网金融解决方案提供商之一。

### 核心优势

**面向敏感输入场景设计:** 围绕密码、证件号、银行卡号、金额等输入场景提供安全键盘能力,降低业务侧自研成本。

**输入链路安全增强:** 支持乱序、加密、密文回调、防截屏、禁止复制等能力,降低输入过程中的泄露风险。

**适配多种输入形态:** 同时支持普通文本输入和 Web 场景键盘,覆盖 App 与 H5 混合业务。

**业务规则内置:** 内置身份证、金额、纯数字、字母符号等键盘类型,并支持长度和小数位控制,减少业务侧重复开发。
