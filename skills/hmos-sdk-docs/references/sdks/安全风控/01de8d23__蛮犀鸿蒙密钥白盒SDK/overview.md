### SDK介绍

本 SDK 主要在本地执行白盒加密、单向协议封装和 native 混淆逻辑,不主动发起网络请求,不主动采集用户身份信息,不内置第三方统计能力。

### 核心优势

  * 白盒化设计:密钥经过拆分、伪装、掩码混合后参与计算
  * 双算法支持:同时支持 `AES` 与 `SM4`
  * 协议一体化:内置单向请求格式、报文检查和服务端提示生成
  * ArkTS + Native 双层实现:既有上层易集成接口,也有 native 混淆辅助
  * 接入轻量:以 HAR 方式输出,调用入口清晰

  * 当前版本为 Demo 型白盒实现,用于方案演示与集成验证,不等同于高强度商用白盒产品
  * `oneWay` 模式仅支持客户端加密上送,不支持客户端反向解密
  * 文件接口依赖业务方提供可访问路径
  * native 构建依赖本地 HarmonyOS CMake / Ninja 工具链配置正确
