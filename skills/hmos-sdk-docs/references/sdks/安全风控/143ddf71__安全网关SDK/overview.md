### SDK介绍

安全网关SDK,是一个提供外网访问内网业务能力的组件,可以运行在鸿蒙应用中。本库基于鸿蒙操作系统进行适配,使其可以运行在 HarmonyOS 中,并沿用其现有用法和特性。

  * 创建从终端到网关的加密隧道
  * 通过 VPN 转发指定应用数据到加密隧道
  * 加密隧道保护传输数据
  * 支持应用数据分流(仅转发指定应用)

### 核心优势

安全网关SDK基于国密算法来保障数据安全性,相较于传统VPN授权放大的痛点,采用转发+代理的模式对访问授权、流量阈值、传输速率等进行动态且细粒度的控制,按照零信任要求的安全规范收束用户可访问的业务范围,避免传统VPN可能导致的横向扩散风险,可根据企业环境灵活定制权限管控。
