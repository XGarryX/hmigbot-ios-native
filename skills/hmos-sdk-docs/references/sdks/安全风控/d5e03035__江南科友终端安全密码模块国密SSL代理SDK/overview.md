### SDK介绍

江南科友终端安全密码模块国密SSL代理SDK支持国际、国密算法SSL协议,为开发人员提供快速构建SSL连接的能力。该产品支持单项、双向SSL认证,支持多种算法的密码套件,通过集成该SDK,可快速实现客户端与服务端之间的身份鉴别、重要数据传输的机密性、完整性和抗抵赖等合规要求。

### 提供商介绍

广州江南科友科技股份有限公司(简称:江南科友)成立于1991年,是国内领先的商用密码产品和服务提供商,专注于数据安全领域。江南科友致力于为客户构建可持续的密码安全支撑体系,为数字环境更安全、更合规、更可靠发展保驾护航。

经过30多年发展,江南科友以密码技术为基础,形成了全面丰富的商用密码产品线和解决方案,为客户提供多层次、多领域的信息保护,凭借优异的创新研发能力、稳定可靠的产品质量、良好的技术支持服务赢得了市场认可。
