### SDK介绍

密鸽移动端SDK具备全格式移动端文件加解密能力,各类文档、图片、压缩文件均可快速加密处理。加密文件可直接通过邮箱、QQ 等社交软件正常转发传输,未授权设备无法解析读取内容,有效阻断数据外泄。支持内嵌至移动办公类应用,还可适配政务 U 盾完成身份核验,满足移动端数据保密管控需求。

### 核心优势

密鸽移动端 SDK 核心优势聚焦安全、兼容、易用、适配四大维度,打造差异化文件防护能力:

安全防护差异化:采用底层加密技术,文件外发后无授权无法解密读取,从源头阻断社交渠道转发泄密风险,同时支持 U 盾硬件认证,满足高等级合规场景需求;

兼容性优势:全格式文件兼容,适配邮件、QQ 等主流社交工具的文件流转场景,无需改造传输链路,加密文件可直接正常转发;

集成与性能优势:轻量化 SDK 架构,接入成本低、适配周期短,不占用过多系统资源,保障移动端 APP 运行流畅无卡顿;

场景适配优势:兼顾企业日常移动办公与政务涉密办公场景,可灵活嵌入各类业务 APP,适配不同行业的文件保密与数据安全管控需求。
