### SDK介绍

云核客户端安全组件为用户提供报文加解密安全能力,覆盖移动客户端与服务端之间的请求提交与响应回执全流程,保障报文数据的完整性与保密性,有效防止信息被破译、篡改、插入、删除及重复发送。组件支持国密算法处理,可适配大报文数据传输,并通过设置防重放因子实现一次一密提交,抵御回放攻击,同时具备反调试、反注入、抗反汇编等安全防护能力。组件兼容多种国密及国际通用密码算法,国密算法包含SM2、SM3、SM4等商用密码算法,国际算法支持3DES、AES、RSA、SHA系列等,满足多样化安全加密需求。

### 核心优势

  * 实现客户端与服务端通信全流程报文安全防护,有效保障数据完整性与保密性。
  * 全面支持国密 SM2/SM3/SM4 及国际通用加密算法,满足多样化安全加密需求。
  * 具备防重放、反调试、反注入、抗反汇编等多重安全能力,抵御各类攻击风险。
  * 支持大报文传输,可实现一次一密、一机一密,加解密处理达到毫秒级性能。
  * 采用分层模块化架构,扩展性强,可灵活适配大数据、信贷等多场景安全接入。
