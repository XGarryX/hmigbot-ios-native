### SDK介绍

邦盛设备指纹Pro,即超级设备指纹,为设备生成唯一ID,具有跨渠道设备识别唯一的能力,真正做到同一台设备打开App、H5、小程序生成同一个设备指纹。同时,提升了传统设备指纹的稳定性,能在设备改机、系统重置、卸载重置、抹机还原等场景下,保持设备的唯一ID不变。

  * 具有准确性高、稳定性强、一致性高的特性。

准确性:又指唯一性,每个设备都会生成一个唯一的设备指纹,不同设备不会生成相同设备指纹。

稳定性:同一设备生成的设备指纹,能够长期保持稳定不改变。

一致性:同一设备支持跨渠道生成同一个设备指纹。

  * 赋能以下业务场景:

风险识别:通过设备维度识别业务风险,包括但不限于交易反欺诈、申请反欺诈、营销反欺诈。

认证领域:通过建立可信设备维度或设备认证,提升用户体验。

营销领域:实现精准营销,识别有效流量,降低营销成本。

运营管理:实现员工行为风险识别,助力企业级数字化转型。
