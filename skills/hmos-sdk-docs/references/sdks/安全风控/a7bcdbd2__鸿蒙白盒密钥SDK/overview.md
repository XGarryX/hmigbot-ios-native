### SDK介绍

鸿蒙白盒密钥SDK是360自主研发的高安全密钥保护方案。用户通过360白盒密钥系统生成白盒秘钥表,并将白盒密钥表进行高安全性的封装,生成白盒密钥SDK,之后进行安全调用。
