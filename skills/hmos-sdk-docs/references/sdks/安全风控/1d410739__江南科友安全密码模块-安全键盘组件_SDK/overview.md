### SDK介绍

江南科友安全密码模块-安全键盘组件 SDK,是敏感信息输入保护组件。通过自定义键盘替代系统原生键盘,提供多重安全防护:

  * 防窃听:隔离系统键盘输入,防止恶意软件监听按键事件
  * 防录屏/截屏:阻止屏幕录制与截图捕获敏感内容
  * 防钩子:抵御键盘钩子攻击,保障输入数据安全
  * 输入混淆:支持按键乱序与密文显示,增加逆向破解难度
