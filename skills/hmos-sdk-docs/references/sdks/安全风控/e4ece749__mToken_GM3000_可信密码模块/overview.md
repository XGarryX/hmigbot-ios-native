### SDK介绍

mToken GM3000可信密码模块是龙脉科技自主研发设计支持国密算法、完全遵照国家密码管理局颁布的《智能IC卡及智能密码钥匙密码应用接口规范》要求设计的USB Key,采用国产高性能智能卡芯片,内置SM1、SM2、SM3、SM4等国产算法,支持高速数据国密算法加解密,支持证书下载和查看、密钥存储、Key密码修改、签名验签、加解密等功能,有效保障数据的机密性、完整性、真实性和持有者行为的不可抵赖性,有效防止被不法分子篡改信息的风险。

### 核心优势

  * mToken GM3000 可信密码模块,广泛应用于电子政务、电子军务,CA厂商、社保、医保,教育、财政、税务、能源等领域;

  * 硬件支持RSA1024/2048, SM2

  * 内置真随机数发生器

  * 支持多操作系统
