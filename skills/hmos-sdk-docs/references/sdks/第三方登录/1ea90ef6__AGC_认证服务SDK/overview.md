### SDK介绍

AGC 认证服务SDK ,助力开发者的应用迅速搭建起安全可靠的用户认证系统,开发者只需在应用中调用认证服务的相关功能,无需担心云侧的设施和实现细节。

  * 支持手机账号注册和登录
  * 支持邮箱账号注册和登录
  * 支持华为账号登录
  * 支持获取用于CloudFoundationKit初始化方法的AuthProvider
