### SDK介绍

天翼账号是中国电信打造的面向数字生活领域的统一账号体系,面向2B2H2G市场,全面赋能数字生活业务发展,落实国家十四五规划对数字中国的战略部署。天翼账号一方面作为中国电信体系内统一账号体系,融通电信各业务体系,积极推进云改数转,提供丰富原子能力赋能体系内业务发展;另一方面,作为是连接运营商和互联网公司的桥梁,基于运营商独有的手机号码识别等智能认证能力,提供智能化互联网认证及用户识别解决方案。天翼账号具有中国电信独家免密认证能力,其特有的电信能力,能够为合作方提供有价值的能力合作与输出。目前天翼账号已与京东、淘宝、抖音、美图、今日头条、腾讯WIFI管家、小米、爱奇艺、招商银行、天猫、航旅纵横等数百个互联网应用达成合作。
