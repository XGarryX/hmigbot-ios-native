### SDK介绍

QuickGame SDK(鸿蒙版)是一套面向 HarmonyOS 游戏联运场景的 HAR 形态 SDK,在鸿蒙工程中以 ohpm 依赖(gamesdklibrary)方式集成,为宿主应用提供与 QuickGame 联运体系一致的 账号、支付、合规流程 等能力。

本 SDK 基于 鸿蒙 ArkTS / Stage 模型 开发与适配,运行于 HarmonyOS NEXT 终端环境,与宿主应用共享生命周期,通过 GameSDKManager 等接口完成初始化、登录、支付及事件通知;可选能力(如本机号码一键登录、抖音登录、巨量转化、QuickAds)可按 发行包配置 编入或裁剪,未编入时不会加载对应第三方模块。

主要能力概览:

联运账号:手机号短信验证码、QQ、微信、华为账号、官方账号等登录方式(以实际发行包为准)

用户协议与隐私授权弹窗、登录态与登出、通知中心回调

联运支付与 应用内购买(IAP) 流程衔接、订单与支付结果回调

实名认证与防沉迷相关流程衔接

可选:阿里云号码认证一键登录、抖音授权、巨量转化、QuickAds 等(按客户构建配置)

技术形态: HAR 依赖集成;Release 构建支持混淆与产物裁剪规则(以包内 consumer-rules / 构建说明为准)。

### 提供商介绍

QuickSDK是一家为全球手游发行提供解决方案的服务平台。通过SDK聚合工具,官方SDK系统,玩家维护系统和数据运营平台等服务,为手游发行商节省研发成本,提高发行效率和增加游戏收益。全球已经超过万余款手游通过QuickSDK进行上线发行,其中包括多家手游龙头企业。秉承一键联接,全心服务的宗旨,QuickSDK会持续助力全球手游产业的良性发展,为手游发行提供更加专业、安全、稳定的全栈解决方案。

### 核心优势

鸿蒙适配:以 HAR + ArkTS 交付,贴合 Stage 模型与 ohpm 依赖管理,便于与现有鸿蒙工程集成。

可按客户裁剪:登录扩展(如一键登录、抖音)、广告转化(巨量)、统计(QuickAds)等可按构建配置 编入或剔除,控制包体与合规披露范围。

工程化与可维护性:提供接入文档、Demo 工程与发布目录结构;支持 Release 混淆与版本号策略,便于渠道侧缓存刷新与问题定位。

合规指引配套:提供《SDK 合规使用指南》等披露模板,支持「同意后初始化」等上架常见要求。

### 约束与限制

运行环境:宿主应用须为 HarmonyOS 且满足工程配置的 兼容 API 与目标 API;具体以贵司工程 build-profile.json5 / app.json5 为准。

本仓库 Demo / 发行工程参考配置(随版本迭代可能调整,集成方以自身工程为准):

compatibleSdkVersion:5.0.0(12)(API 12)

targetSdkVersion:6.0.2(22)(API 22)

开发工具:建议使用 DevEco Studio 官方发行版,与当前 HarmonyOS SDK 版本匹配;升级 IDE/SDK 后需重新全量编译与真机验证。

可选依赖:若发行包启用了号码认证、抖音、巨量等能力,宿主须按接入文档声明 对应 ohpm 依赖与权限,否则可能出现模块缺失或运行时错误。

网络与安全:登录、支付、配置拉取等依赖网络;生产环境须使用 HTTPS 与贵司认可的证书策略。

初始化时机:须在 用户同意隐私政策之后 再调用 SDK 初始化(详见《SDK 合规使用指南》)。
