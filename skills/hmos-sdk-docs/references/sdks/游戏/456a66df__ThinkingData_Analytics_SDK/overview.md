### SDK介绍

数数分析SDK,是一款数据上报的工具SDK,可以运行在鸿蒙操作系统。本库基于鸿蒙操作系统进行适配,使其可以运行在HarmonyOS中,并沿用其现有用法和特性。

  * http 请求
  * 批量数据上报
  * 本地数据加密(RSA+AES)
  * 时间校准
  * 全埋点

### 提供商介绍

数数信息科技(上海)有限公司创立于 2015 年,全球游戏数据基础设施开创者,公司在全球多个城市,包括上海、东京、首尔、新加坡设有办公室。

数数科技研发的游戏行业数据基础设施 ThinkingEngine(简称“TE 系统”),为全球游戏打造一体化数据驱动解决方案,满足游戏企业全品类、全场景、全生命周期的数据需求。TE 系统具备数据分析、精细化运营、数据开发等多种能力,可帮助游戏企业通过数据驱动增长。

目前,数数科技已服务超过 1200 家游戏企业,其中包括 FunPlus、中手游、叠纸游戏、IGG、雷霆游戏、库洛游戏、三七互娱、点点互动、Habby 等知名游戏公司。旗下 TE 系统接入的游戏超过 6000 款,其中包括《鸣潮》《寻道大千》《恋与深空》《弹壳特攻队》《无尽冬日》《羊了个羊》《王国纪元》等爆款。

### 核心优势

  * 功能丰富,接口齐全

数数分析SDK涵盖多种功能点,包括但不限于批量数据上报、全埋点、时间校准,多实例,支持在Work线程使用,App与H5打通,满足不同集成方不同业务需要。

  * 易用性

提供详细的说明文档和专业的对接人员,帮助开发人员快速上手,短时间内快速接入。

  * 稳定性

经过严格的测试和优化,包括但不限于高覆盖率的自动化测试、单元测试等,保证了SDK的稳定性和可靠性,确保集成方的业务不受影响。
