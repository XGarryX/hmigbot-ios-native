# RichTap SDK for HarmonyOS 合规使用指南

为帮助使用RichTap SDK的客户(以下简称“您”)在符合个人信息保护相关法律法规、政策及标准的

规定下合规接入、使用RichTap SDK,本组织(以下简称“RichTap”)特制定本文档,便于您使用

RichTap SDK过程中符合相应的合规要求。请您在接入、使用RichTap SDK前,充分阅读和了解本文档

内容。

## 一、 SDK 功能概述及个人信息处理说明

### 1.SDK 功能

RichTap SDK 是一款专注于提供高品质触觉反馈(Haptics)体验的开发工具包。

-
核心功能:通过SDK接口,调用HarmonyOS 设备的振动能力。

-
支持能力:支持振动效果文件(HarmonyOS JSON格式、HE格式等)的播放、暂停、媒体同步等

高级控制功能。

-
使用目的:为终端用户提供沉浸式的游戏、影音、操作交互等场景的触觉反馈体验。

### 2.个人信息处理说明

RichTap SDK 本身不收集、不处理、不存储终端用户的个人信息。

-
处理类型: RichTap SDK 的功能仅涉及对HarmonyOS 设备硬件(振动马达)的调用和控制。

-
不收集信息:本SDK不涉及收集或回传终端用户的设备标识符(AAID/OAID/IMEI等)、地理位

置、应用列表、传感器数据、麦克风/摄像头数据、电话信息、个人生物识别信息等任何个人信

息。

-
数据安全:您在App中使用SDK播放振动效果文件的行为和数据,均在用户的设备本机运行,不会

上传至RichTap的服务器。

## 三、 SDK 初始化及用户同意前置原则

由于RichTap SDK的运作不依赖于个人信息,因此在初始化方面无需遵循“先同意后初始化”的严格限

制。

但为了确保整体App的合规性,强烈建议您遵循以下原则:

1.最小化初始化:在App启动后,仅加载SDK的核心模块,但不执行任何可能触发权限调用或功能使

用的操作。

2.同意后调用功能:尽管RichTap SDK不收集个人信息,但您App的其他基础功能可能需要用户同

意。为确保App整体符合监管要求,请您在获得用户对App《隐私政策》的明确同意后,再调用

RichTap SDK 的播放振动等具体功能接口。

技术操作建议:

-
在App首次启动时,等待用户明确同意您的《隐私政策》。

-
获得同意后,再调用 RichTap SDK 的初始化方法,或在需要使用振动功能时,执行振动播放逻

辑。
