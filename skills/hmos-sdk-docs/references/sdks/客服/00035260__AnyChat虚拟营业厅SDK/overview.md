### SDK介绍

1、支持HarmonyOS平台设备上的虚拟营业厅应用开发;

2、深度融合OCR识别、人脸比对、活体检测、人脸深伪检测等多种AI能力,保障视频银行业务合规,提供业务办理效率;

3、支持纯鸿蒙渠道接入统一进行业务办理,线上完成业务的办理,支持理财双录风险测评、理财业务咨询与推介、消费信贷与面审、对公开户法人面签、个人账户密码重置、贷款远程面签等成熟业务应用场景。
