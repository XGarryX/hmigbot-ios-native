### SDK介绍

1、支持HarmonyOS平台设备上的智能坐席应用开发;

2、集成人脸识别、活体检测、语音识别、人脸识别等多种AI能力;

3、支持智能排队、坐席转接、风险揭示、视频标签等坐席能力;

4、支持金融(远程视频银行、在线开户、理财顾问、视频面审)、政务(视频咨询、远程帮办、政务事项视频办理)、医疗(远程会诊、视频问诊)等场景的远程视频客服与智能面审业务。
