### SDK介绍

美摄视频编辑创作SDK是一套完全自主研发的跨平台的视音频处理引擎,支持全流程丰富的处理功能,其高效、低消耗、易扩展,为开发者提供具有竞争力的视音频拍摄及编辑SDK能力。

### 提供商介绍

美摄科技成立于2014年,是AIGC智能视音频解决方案服务商。我们坚持技术创新。基于专业的视音频和AI技术,为来自不同国家和地区、各行各业的商业用户提供个性化视音频解决方案,帮助企业搭建高品质视音频业务,实现业务增长和商业成功。美摄科技核心成员专注视音频引擎研发、图形图像处理、计算机视觉领域开发20余年,持有70余项相关专利。团队成员参与的项目曾荣获多项国家级奖项,拥有深厚的技术积淀和丰富的企业服务经验。

### 核心优势

**1、8K &16K级别视频制作**

美摄视频编辑创作SDK在移动端达到广电标准的视频制作能力,支持8K级别拍摄和编辑,16K图片处理,无需预处理即可实时特效渲染,独有的视频处理架构针对不同设备平台进行驱动级优化,在保证高质量输出的情况下仍然拥有优秀的生成速度。

**2、强大的性能效率**

美摄视频编辑创作SDK专业的非编架构引擎,无论拍摄编辑,任何特效均可实时渲染预览,大大提升制作的流畅性,带来优质的客户体验。强大的性能效率,能覆盖各类低端硬件,包括智能手表的平台也可以保证使用效率。

**3、专业剪辑功能**

美摄视频编辑创作SDK提供丰富且专业的剪辑功能,满足对于从视频、音频、图片等各种类型的制作处理需求,同时灵活的接入方式可以让用户根据自己的需求自由搭配组合,创建新玩法。

**4、惊艳的滤镜特效**

美摄视频编辑创作SDK广受好评的滤镜系统,专业的调色,复杂的动画,艺术化特效均可以通过滤镜实现,并可在拍摄编辑中任意添加使用。

**5、专业的字幕能力**

美摄视频编辑创作SDK专业的字幕SDK,将电视节目演播室级的字幕能力移植到了移动端、web端pc端等,通过丰富的样式、动画和渲染处理能力,实现专业节目中才有的字幕效果。

**6、构建跨平台、多端互通应用开发**

美摄视频编辑创作SDK覆盖移动端、云端、PC端、硬件、工程文件、特效、滤镜等功能全打通,支持Flutter、React Native等优质应用开发框架,方便企业快速接入部署。

**7、低成本快速接入**

美摄视频编辑创作SDK提供丰富的产品SDK和DEMO体验,企业只需调用少量接口即可接入,简单易用,降低开发者门槛,还可根据自身需求加入自研技术或其他第三方技术。

**8、丰富的版权素材资源**

美摄视频编辑创作SDK提供滤镜、字幕、转场、道具、贴纸、美妆、粒子、模板、字体、音效等丰富的版权素材,至今已有近万种素材资源积累,多种方式供企业灵活选购。
