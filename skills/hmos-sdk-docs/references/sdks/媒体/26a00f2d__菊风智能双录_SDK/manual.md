# 三、双录功能(PC 端) 

## 1、语速调节 

TTS 播报的速度分为慢速(0.5x),正常(1.0x),快速(2.0x),每次选择之后需要在下一次播报的 时候生效。默认1.0x 倍速。 

## 2、 播报方式 

播报方式分为人工双录和AI 双录,默认是AI 双录。 

## 3、 截图功能 

点击“截图”,可以根据不同角色进行截图。截图是摄像头截图,保存录制中真实的片段; 

## 4、 环节选择 

远程-双录录制前,可点击“环节选择”,自定义选择节点流程; 

点击“环节选择”,弹框显示所有的节点选项; 

客户经理根据业务场景需要,自定义选择一些节点,确定保存。 

办理流程按照选择后的环节,开始录制; 

## 5、 人脸同框 

根据订单中的人数,需要和订单中配置相同的人数入框 

- 大于订单中配置相同的人数,2 人在框 

- 小于订单中配置相同的人数,0 人在框 

## 6、 人脸对比 

人脸对比的前提是人脸在框和标准图已经上传,且人脸在框正常,用标准图中的图片和框中的人 脸进行对比。 

- 人脸有遮挡 

- 人脸对比失败 

- 人脸对比成功
