### **SDK 介绍**

拓课云 HarmonyOS NEXT SDK 是专为 HarmonyOS 系统设计的实时互动课堂 SDK,完全基于 HarmonyOS 开发。提供开箱即用的 UI SDK 与可深度定制的无 UI SDK,支持实时音视频通话、互动白板、屏幕共享、消息聊天、录制回放等功能。采用 WebRTC 优化协议,具备超低延迟(<300ms)、抗弱网、高并发稳定等特性,适用于在线教育、企业培训、远程医疗等实时互动场景。

### **提供商介绍**

拓课云(Talk-Cloud)是国内领先的实时音视频(RTC)云服务商,专精特新“小巨人”企业。自2016年成立以来,已服务超过 8,000 家企业客户,覆盖在线教育、金融、政府、互联网等众多行业。公司总部位于北京,并在上海、深圳、成都等地设有分支机构,提供从 PaaS 到 SaaS 的全场景音视频解决方案及一对一的专业技术支持服务。

### **核心优势**

  * 鸿蒙适配,性能最优:基于 ArkTS 语言开发,无跨端桥接损耗,内存占用较传统方案降低 30%,启动速度提升 25%。
  * 超低延迟互动:依托自研 RTC 引擎与智能路由算法,在 70% 丢包率下音视频依然流畅,端到端延迟可控制在 300ms 以内。
  * 全场景兼容:完美适配 ArkUI 声明式开发范式,与鸿蒙分布式能力(多设备流转、一次开发多端部署)无缝协同。
  * 模块化设计:UI SDK 与无 UI SDK 自由切换,支持白板、聊天、成员管理等组件按需集成,减少包体积增量。
