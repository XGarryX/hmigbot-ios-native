# Demo 使用说明: 

1. 小鱼易连音视频 SDK 和会议 SDK 共用一个 Demo ,即: XYHMSDKDemo 

2. 最低支持版本 5.0.1(13) 

3. Demo 目录新建 XYHMLibs 文件夹 , 然后将 xylink_libs_uikit 、 xylink_libs_base 、 xylink_libs_chat 、 xylink_libs_xyhmsdk 、 xylink_libs_meetingkit 

4. 执行 ohpm install 

5. 配置证书运行即可 ( 初始化、登录、会议信息均已内置 ) 如需变更 可联系工作人员 

备注 : 

仅支持真机运行 

也可参考在线文档(小鱼易连音视频 SDK 使用说明): 

https://openapi.xylink.com/common/meeting/doc/ready_work? platform=harmony
