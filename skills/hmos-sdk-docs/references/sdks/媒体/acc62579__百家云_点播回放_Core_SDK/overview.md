### SDK介绍

百家云点播回放 Core SDK 基于百家云自研的高可靠、高性能多媒体处理与分发平台,是一款聚焦底层播放能力的核心引擎解决方案。它为企业及开发者提供纯粹的播放控制与数据处理能力,不绑定任何 UI 组件,适用于对界面有完全自定义需求的场景,如嵌入式播放、自定义播放器开发、跨平台播放集成等。主要包括:视频播放控制、进度记忆、倍速播放、清晰度切换、数据埋点等底层接口。SDK 不提供预设 UI,赋予开发者最大化的自定义空间,支持与任意 UI 框架结合,具备高度的灵活性与二次开发能力。

### 核心优势

  * 纯底层核心,完全自主构建

不提供任何预设 UI,仅暴露核心播放能力接口。开发者可根据业务需求,从零构建播放界面与交互逻辑,适用于对 UI 有极致定制化要求的场景。

  * 流畅播放,体验卓越

基于百家云自研的多媒体处理与分发平台,采用智能调度与自适应码率技术,保障视频起播快、播放流畅。支持多清晰度无缝切换,适配不同网络环境。

  * 播放控制,功能完整

提供完善的底层播放控制接口,包括:播放/暂停、进度控制、倍速播放(0.5x-2.0x)、音量调节、清晰度切换等。支持播放进度自动记忆,便于上层业务实现断点续播。
