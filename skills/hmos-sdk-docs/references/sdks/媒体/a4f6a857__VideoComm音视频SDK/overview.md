### SDK介绍

VideoComm音视频SDK是我们核心团队成员基于多年的音视频通信领域的技术积累,为客户提供跨终端、多平台互通、低成本、高品质、可定制的实时音视频通信服务的开发平台,在平台中提供了音视频通信、音视频录制、文件传输、数据通信、业务排队、屏幕共享等能力。

我们的目标是让客户在无需音视频技术基础的情况下,都可以通过本开发平台从零开始即刻搭建出自己的专属音视频通信应用解决方案。

### 提供商介绍

广州视通网络科技有限公司(简称:视通科技),我们专注于音视频通信前沿技术的研究,致力成为国内领先的音视频平台服务提供商,自主研发VideoComm音视频平台产品。视通科技核心研发成员均来自国内音视频通讯领域顶尖人才,在音视频通信行业有长达十多年的核心技术积累。技术团队成员长期服务于金融、教育、医疗、智能硬件等行业音视频应用项目工作一线,为近千家客户提供优质的服务,赢得客户的信赖和认可。

### 核心优势

  * 新一代音视频引擎

高效支持VP8、VP9、H264、H.265等多种编解码引擎,保证高清音视频实时通信质量。

  * 融合AI智能服务

融合了多种AI能力,打造智能化音视频服务,为客户带来服务更便捷、成本更低、效率更高的应用价新一代音视频引擎。

  * 高可靠性

产品支持分布式集群架构和负载均衡技术,实现音视频流的负载均衡,提供了强大的容灾能力。

  * 集成周期短、节省费用

提供示例程序Demo,通过API接口进行集成,支持主流开发语言。
