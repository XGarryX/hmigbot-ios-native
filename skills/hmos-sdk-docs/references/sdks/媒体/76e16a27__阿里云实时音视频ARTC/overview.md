### SDK介绍

传统直播以单向内容传播为主,观众参与度和商业转换效率低。阿里云实时音视频(ApsaraVideo Real-time Communication)在传统直播基础上加入了更多互动元素,如语音聊天 、视频连麦、游戏互动等,让观众不仅是观看者,也是参与者,增强平台用户之间的连接。本文介绍了实时音视频的产品架构、应用场景、功能特性等相关内容。现已兼容鸿蒙最新版本HarmonyOS NEXT,为开发者在鸿蒙平台上提供实时音视频互动体验。

### 提供商介绍

阿里云计算有限公司(Alibaba Cloud Computing Co., Ltd.)是阿里巴巴集团旗下的全资子公司,成立于2009年,总部位于中国杭州。作为全球领先的云计算服务提供商,阿里云致力于为企业和开发者提供全面的云计算、大数据、人工智能等技术服务,助力企业实现数字化转型和业务创新。

### 核心优势

  1. 优秀质量

     * 复用CDN全球3200+节点,在全球范围提供高质量服务
     * 声学优势:提供智能降噪、双声道、空间音频服务,提升用户体验

  2. 安全合规

     * 全球通话合规资质完整
     * 隐私保护标准认证“全满贯”
     * 满足全球主流金融业权威标准要求

  3. 解决方案一盘棋
     * 联动ECS、OSS、安全、直播、点播、数字人等产品形成一站式解决方案。示例:与超低延时直播联动,能实现上麦下麦平台切换;公共云整体商务解决方案
  4. 易于集成

     * 含UI的集成:提供开源界面示例代码、UI组件,简化开发难度
     * 场景化API集成:将底层原子API接口从业务场景视角进行封装,简化开发难度
     * 多场景提供,涵盖1V1通话、直播连麦、语聊房、KTV等场景

### 成功案例 

  1. 淘宝直播
     * 场景:电商直播,单向视频流直播、双向连麦互动直播
     * 方案:
       * 直播全场景应用RTC方案

       * H265传输,保障画质和码率

       * 自动降级TCP路线,解决UDP极端情况不可用场景

       * 全球节点3200节点承接服务,观看人数不受限制

  2. UC浏览器

  * 场景:社交娱乐直播、跨房间主播PK
  * 方案:
    * 声音:立体声双通道

    * 视频:1080P + H265

    * 自研Qos策略,提供高清流畅的通话体验

    * 提供完善的SEI策略、排障系统、监控体系
