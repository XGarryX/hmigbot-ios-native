### SDK介绍

基于鸿蒙ArkTs语言开发,运行在HarmonyOS NEXT系统上的聚合广告SDK,能够帮助开发者一键集成多个广告预算来源,统一管理代码和各方的资源文件,并且通过热插拔的方式满足开发者各个使用场景的需求。同时ToBid聚合SDK内置的各项预算分配、调优能力,比如应用内竞价(headerbidding)、瀑布流等,也可以帮助开发者在使用最先进广告加载技术的同时,享有最大化的收益。
