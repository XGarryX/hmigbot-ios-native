### SDK介绍

浩宜语音识别SDK ,是一个基于 promise 的网络请求库,可以运行鸿蒙设备上。SDK基于鸿蒙操作系统进行适配,使其可以运行在 HarmonyOS中,并沿用其现有用法和特性。

  * 基于audio及audiocapturer进行实时获取音频流
  * 实时传输音频流给服务引擎
  * 核心逻辑算法处理音频流片段及兼容性
  * http 请求,获取识别结果
  * 转换 request 和 response 的 data 数据
  * 自动转换 JSON data 数据
