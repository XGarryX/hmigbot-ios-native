### SDK介绍

文通银行卡OCR识别SDK是文通科技基于业界领先OCR识别技术,自主研发的一款OCR识别产品;银行卡识别支持横卡、竖卡、异型卡、背面卡均可识别;支持导入识别和拍照识别(四边检测、智能检边、手动拍照)等多种录入方式;可输出卡号、有效期、姓名等字段信息;支持打开闪光灯,支持暗环境下扫描识别;内置卡宾表、支持发卡行等信息的输出。
