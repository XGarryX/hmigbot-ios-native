覆盖证照类型全面

基于 HarmonyOS 深度适配,沿用原有用法与特性,保障在鸿蒙系统中的稳定运行与高效性能。

集成便捷,开发效率高

保留原有使用习惯,降低迁移与接入成本,帮助开发者快速完成卡证识别功能的集成。
