### SDK介绍

实时语音转写(ASR, real-time)通过 WebSocket 协议,建立客户端与服务的长连接,开发者将连续的音频流内容发送给服务,服务返回对应的文字流内容。

  * 准确率高:语音行业多年沉淀,打磨出业内一流的语音识别算法和模型,准确率可达实用标准
  * 识别速度快:首包响应时间毫秒级,并实时展示中间文字结果,快速识别音频流
  * 个性化热词:将一些不常见、专业性的名词上传,定点提升部分词汇识别准确率。支持应用级和任务级热词
  * 数字/敏感词处理:对结果中出现数字、日期、时间等内容格式化成规整的文本,敏感词支持处理后输出
