# SDK介绍  

基础技术SDK 是一款专注于语音的开发工具包,支持在线语音合成(TTS)功能,为设备提供将文字信息转化为声音信息的能力。本SDK基于HarmonyOS进行深度适配,确保在鸿蒙生态中高效运行

# 核心功能  

**在线语音合成(TTS):** 实时将文字转换为语音,支持多种音色,速度。  

**模块化接入:** 可独立集成TTS服务,或与其他技术组合使用。  

# 提供商介绍  

思必驰是一家领先的智能语音技术提供商,专注于语音识别、自然语言处理等人工智能核心技术的研发与应用。公司总部位于苏州,并在深圳、北京等地设有研发中心,服务覆盖车载、IoT、智能硬件等多个行业,为全球企业提供高性能、可定制的语音解决方案。凭借深厚的技术积累和行业经验,已成功助力数百家企业实现语音交互智能化升级
