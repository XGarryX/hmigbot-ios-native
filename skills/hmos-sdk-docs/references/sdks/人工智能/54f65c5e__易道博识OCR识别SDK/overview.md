### SDK介绍

易道博识OCR识别SDK,采用深度学习OCR技术,通过手机或带有摄像头的终端设备对证件进行拍照,或者直接输入静态图片,即可快速完成证件的识别,输出结构化数据。

  * 深度学习OCR技术
  * 图像的矫正与裁剪
  * 证件质检

### 提供商介绍

北京易道博识科技有限公司由中科院、清华、北大专家创立,专注于全球领先的模式识别与人工智能解决方案。公司拥有自主知识产权的多项核心技术,涵盖文字识别、3D人脸识别、图像识别三大领域,其中3D人脸识别为国内唯一自主研发产品。凭借深度学习和创新压缩技术,易道博识在OCR识别率、算法效率方面处于行业前沿,广泛服务于银行、证券、保险、汽车金融、能源、通信、互联网等行业,客户超过500家,致力于引领智能识别未来。

### 核心优势

  * 基于深度学习技术
  * 支持预览模式下的视频流识别
  * 头像提取

  * 支持任意角度扫描模式

  * 支持基于License文件授权
  * 提供批量识别率测试工具
  * 具有良好的可扩展性,可快速支持新证件的模型化识别功能
