### SDK介绍

基于语音识别和评价技术对发音做客观打分,反馈发音正误和定位问题,有助于语音教学,发音练习,也可测试考生的口语水平。

  * 评测维度有总分、完整度、发音标准度和流利度
  * 支持输出语速、重读、连读和升降调
  * 可以精细到单词的音素打分
  * 考试题型也可以输出总分、标准度、流利度和完整度
  * 中文评测支持声母、韵母和声调和字的分数输出
