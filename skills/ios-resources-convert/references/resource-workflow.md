# iOS 资源映射记录

逐条保存 source target/bundle、path、hash、原始名称、variant 条件、转换方式、
目标路径/名称和实际校验结果。variant 不是可以随便丢弃的重复文件。
本地化记录参数、复数规则和 fallback；不把所有 xcstrings 项直接扁平为一个中文值。

字面量记录分清三类信息：`source_expression` 是完整源表达式，`value` 只用于已支持且已解码的静态值，
`decoding_status: unresolved` 表示尚无确定值。Swift 扩展分隔符字符串的转义/插值取决于匹配的
`#` 数；如 `#"line\nnext"#` 中的 `\n` 不能自动变成换行，内部普通引号也不能截断表达式。
源提取保留完整单行/多行表达式和行范围，未支持的扩展分隔符、多行与插值进入 `dynamic_texts`
并写明确原因。转换时逐项引用原账本来源，另记录确定值的语义证据和目标资源映射；未解码项保留
unresolved，不能因产品归属、相同重提结果或 `page_level` 标记而认定已得到目标文案。
运行时生成图/动态颜色/自定义字体缩放转行为适配，不能靠批量文件复制完成。
兼容格式可直接复用；非兼容格式调用已安装转换器并记录版本，检查真实产物。
SF Symbols 仅记录符号含义与许可/版本约束，不能保证任意系统符号有目标同名项。
资源冲突由单一 owner 合并，新增引用必须可追到真实资源，不用空占位文件过编译。
