# 规格内容复核

以原始源码和已批准决策核对规格，不仅看生成器自述或目标代码。逐功能走完真实入口、输入、状态/数据处理、副作用、错误/取消、持久恢复与反馈。无适用路径给具体理由，不发明补齐模板的逻辑。

复核实例与本次规格作者分离；单代理宿主无法独立派发时披露限制，不自填“独立通过”。输入包括当前源快照、[产物目录](artifact-contracts.md)内适用主MD/伴随件、决策与排除。只检查表头不能完成内容复核。

| 检查 | 问题 |
|---|---|
| 范围 | 是否区分生产、Preview、测试、扩展及平台条件？共享文件是否按符号区分？ |
| 行为 | 输入、公式、分支、具体结果是什么？ |
| 状态 | 谁拥有真值，谁写谁读，重入/身份改变/离开如何处理？ |
| 接口 | 调用两侧类型、单位、nil、句柄、错误和线程是否一致？ |
| 接线 | 页面handler调用谁，反馈怎样回写，组件由谁承载？ |
| AC | 不看目标代码能否得出期望？是否混合不同行为或延迟展开断言？ |
| 证据 | 真值行是否实际发生该行为？是否误用import、注释、Preview？ |
| 消费 | Plan能否按对接点分任务，execute能否按目标锚点和源入口实施？ |

## 必测反例
- import CoreData 不证明保存或重载，需追到实际操作。
- Preview 内示例实体、固定宽度不能作产品初值或视觉验收。
- “对源赋值的边界输入观察结果”需改为实际输入、运算与期望。
- “其余20处原表达式见审阅”需展开可独立判断的断言。
- 公共目标接口不能推给 plan 临场定义；plan 负责施工分配。
- reviewed 字段和哈希齐全不能独自证明语义正确。
- 组件表有行但只写“Column/List，按iOS效果实现”，仍缺条件、布局依据和具体映射。
- 页面写点击后立即退出队列，服务写完成回调移除；不能由消费者任选一个。
- UI已清空、内存已清理、磁盘已删除不可合并成单一完成时点。
- 活动动作/AC仍引用已排除云路径，追加尾注不能替代主合同修订。

## 逐动作跨文档联读

1. 从主feature公开接口、页面交互、API调用及机器义务列本次复核动作；不要只从已生成的action块取分母，否则遗漏的动作永远不可见。
2. 对每个适用动作，打开源handler→状态写入→实际服务→完成/错误/取消→释放；确认完整调用接收者、输入单位和值域、即时与完成时点。
3. 顺序联读公共合同/所属feature的action-contract→消费feature→page交互/状态→稳定AC→skip-list/decision。核对action-use指向唯一精确标题；页面可保留UI投影，不能另定服务终态。
4. 对UI逐页联读组件层级→条件分支→布局来源→具体ArkUI映射→状态Owner/Binding→资源；根/子节点和条件须可从源码重建，不以图像观感代替结构事实。
5. 使用正常、源码存在的错误/取消、离开/重入/重载场景检验合同。区分“已请求”“内存已变”“最终回调”“磁盘完成”；对无分支给源依据，对动态未决保留unknown。

复核记录保存到本次原交接/检查报告中，包含动作或page/F/AC ID、所有读入文件/精确标题、源快照、复核者、结论及finding定位，不另建活动AC/问题账本。报告声称“逐动作”必须有可回查的条目，不能用“均符合”替代。

## Finding、返修与独立复查

发现问题时给：稳定subject ID、冲突双方路径/标题/行、真实源证据、受影响AC/页面/消费者、预期合同、责任owner及blocking范围。语义冲突由复核发现并通过现有finding/报告入口登记；不得手改脚本控制账本或清空其他阶段finding。

原owner修其权威定义并同步全部引用投影；若涉及产品差异，先按原决策协议处理，不借返修自行批准替代。修复说明逐条链接变更，不能只回复“已处理”。

独立复核者重新打开源与双方文档，逐finding验证：定义唯一、时间/类型/范围一致、AC具体且oracle仍独立、受影响引用齐全。再重建受影响派生产物，复跑产生finding的检查，只有该检查实际关闭其finding才可收口。作者的自检和脚本PASS不能替代这次独立复查；新发现继续原闭环。

## 实际检查与交接
先 spec-check 修正内容，再 source-check --harness 检查内容、原生信号/覆盖与专业资料；继续原 addenda、差异、追踪及计划覆盖检查。保留命令、退出码和报告路径。

Gate C 披露 source digest、采用的spec_contract_version、统一覆盖分母、检查范围、独立复核/返修/复查证据和未决/未运行项。生成、结构、源合同、目标编译、行为、视觉分别记状态，旧verified标签不能替代这些证据，不能由本检查表宣称App已验收。
